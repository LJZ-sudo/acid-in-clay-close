## 1. 重复性(钉住误差带 + 解释 6.5× Ea 矛盾)

| 配对 | 匹配温点 | Δlog₁₀σ 均值 | Δlog₁₀σ std | σ 比值中位 | 低温活化段 Ea 一致性 | 高温近无垒段 |
|---|---|---|---|---|---|---|
| LRS 6.12 ↔ 6.15_merged | 37 | 0.086 | 0.127 | **1.23×** | **5.5%**(0.585↔0.618 eV) | ratio 6.49,但**绝对差仅 0.046 eV** |
| starch 6.11 ↔ 6.13 | 34 | 0.066 | 0.046 | **1.13×** | **1.9%**(abs 0.0072 eV) | abs 0.055 eV |

**结论(诚实)**:真正的活化(低温)段 Ea **跨独立批次重复到 1.9–5.5%**,σ 重复到 1.1–1.2 倍。
所谓"6.5× 矛盾"只出现在**高温近无垒段**:该段 Ea 绝对值极小(0.008–0.055 eV,均 ≪ kT),
斜率接近 0,比值由"分母趋零"放大,**绝对差仅 0.046 eV、在测量不确定度内**。
→ 论文应**以低温活化段 Ea 为可复现量**,高温段仅描述为"近无垒",不报单一精确 Ea。

## 2. 物理自洽性 → suspect 点(失败当标签,不删)

判据:`log₁₀σ` vs `1000/T` 的**单调(isotonic)残差 > 0.3 dex(~2×)** = 物理不自洽(σ 应随温单调)。

- 241 个有效点中 **4 个 suspect**,全部在 **−85~−89°C** 极低温、全部 `reverse_valley` Rb 方法。
- 典型:**LRS 6.15 的 −88°C,rb=301.8Ω**(而 −85°C 是 9115Ω,违反单调);LRS 6.12 的 −89°C(rb=178Ω)。
- **关键**:这 4 个点的 **KK 仍然通过(kk_score 0.93–0.95)** → 实证 "Lin-KK 通过 ≠ 物理自洽",
  正是 GPT 反复强调、也是 P2 校准层存在的理由。

## 3. 测量可信度校准(v0 朴素KK vs v1 物理感知)

| 置信定义 | AUROC(识别 suspect) | Brier | ECE | 坏点平均置信 | 好点平均置信 |
|---|---|---|---|---|---|
| v0 = 原始 kk_score(朴素) | 0.956 | 0.0163 | 0.0343 | **0.939** | 0.960 |
| v1 = kk × (1−0.85·显著跳变) | **1.000** | **0.0020** | 0.0367 | **0.141** | 0.960 |

- v1 把 4 个物理坏点的置信从 **0.94 → 0.14**,而好点保持 **0.96 不变**(阈值化只惩罚 >0.2 dex 的显著局部跳变)。
- **headline 指标 = AUROC**(0.956→1.000)与 **Brier**(8× 改善):在 98% 基础率的极不平衡下,这两个比 ECE 更有信息量。
- **诚实标注**:v1 的 **ECE 略升(0.034→0.037)**,因为正常点置信 0.96 对 98% 基础率本就略欠自信;
  这是预期、已如实报告,不隐藏。

## 4. 诚实局限(写论文必须带)

1. label 是**传输侧自洽性代理**(isotonic 单调残差),**不是独立重复命中**;措辞用"transport self-consistency",不声称机理。
2. 样本小(6 条曲线、241 点、4 个 suspect),ECE/AUROC 为 **v0 估计**;扩样品后需复算。
3. `fit_quality` 在 `reverse_zero_crossing` 段是占位常数 0.95,**未用作特征**;只用真实逐点的 `kk_score/kk_mu_max/rb_ohm/rb_method/局部残差`。
4. v0 与 v1 公式均**预先定义**(非 fit 到 label):v1 的 0.2 dex 噪声地板有物理依据(EIS σ 合理噪声上界),非为指标好看而调。

## label 升级(核心区别)

## 真实结果(中等强度,诚实)

| 量 | v2 真实值 |
|---|---|
| 样本(共温点) | **71**(LRS 37 + starch 34) |
| 整体命中率 | **64.8%**(LRS 51.4% 低温复现差 / starch 79.4% 复现好) |
| AUROC(conf_v1 预测独立重复命中) | **0.71**(conf_v0 = 0.708,几乎无差) |
| ECE(isotonic 校准后) | 未校准 0.304 → **~0.14** |
| 容差敏感性 | tol 0.10→命中 64.8%/AUROC 0.71;tol 0.15→命中 74.6%/AUROC 0.68 |
| 经验曲线 | 留出 ECE 在 size 10→45 单调降(0.159→0.136),size=50 因留出仅~21点反弹(0.165) |

## 诚实结论(写论文必须带)

1. **AUROC = 0.71 是中等、非强**:单曲线 QC 把握度对"跨独立重复能否复现"有中等预测力。**不得用 v0 的 1.0 冒充**(那是识别单曲线坏点,容易得多)。
2. **经验曲线只是雏形**:趋势支持"更多重复数据→更好校准",但**两对重复不足以钉死曲线**;这是**校准样本效率**,不是 agent 在线自进化。
3. **(a) 面板可靠性图退化为右端两点**:因为把握度普遍集中在 0.85–0.97(分辨率低)→ 也是"需要更有分辨率的把握度特征 + 更多重复"的真实信号。
4. **直接引出补实验**:把 0.71 抬高、把经验曲线钉死,唯一缺口是**更多独立重复对**(见主文 §11.2 清单:LRS 第3/4次、starch/CHITO 各补1次)。

## 诚实结论(写论文必须带)

1. **单曲线 QC 把握度对"跨片复现"预测力弱(AUROC ~0.55)、且严重过自信(ECE 0.54–0.75)**——这就是"**QC 通过 ≠ 可复现**"的硬证据,正是本项目诚实立场的核心卖点。

4. **引出方法增量(下一篇)**:要让把握度真能预测复现,需**含 Rb 量级/温度的"复现感知把握度"**;校准机器(isotonic on repeats)已可用。
