## 结果分析摘要

- **限域效应**：低温 ΔEa≈0.20 eV（95%CI 0.14–0.25）、高温≈0.05 eV（0.02–0.07），低温 vs 高温差异显著（p<0.001），与“低温限域主导、高温趋同”一致，**可作论文主结论**。
- **模型**：S8 R²=0.97、CV R²=0.81；S60 CV R²=0.89±0.03、MAE=0.07 eV，**均达标**。
- **ML–AI**：step4 所用 R/N 区间**从 S8 深度报告第四部分解析**，与报告一致。高温区区间内 n=4、区间外 n=39，mean(Ea) 差异不显著（p≈0.92）；低温区区间内 n=0。宜写“相容、建议扩大样本再验证”，**不宜写“一致/验证”**。
- **跨材料**：S14（埃洛石+H₃PO₄）迁移最好（α≈1.09）；S13（膨润土+植酸）n=2、α≈0.57；S15（高岭土+植酸）n=1、α≈2.75（全温区单段拟合，结论需谨慎）；S6 偏差大（α≈2.0）；S95–97 模型高估（α<1）。**宜写“迁移性因材料与酸体系而异”**。
- **完整性**：ΔEa 的 CI/显著性、Meyer-Neldel、跨材料验证、可复现性包均已就绪；**S60 深度机理报告已生成**（`deep_analysis/S60_deep_mechanism_analysis.md`），可与 S8 深度报告对照用于 Discussion，**可支撑定稿投稿**。

## 一、结果概览与亮点（已满足或接近发表要求的部分）

### 1.1 限域效应 ΔEa 的温度依赖性（**可支撑论文核心结论**）

| 温区 | mean ΔEa (eV) | 95% CI (bootstrap) | n (segments) |
|------|----------------|---------------------|--------------|
| 低温 (<230K) | **0.198** | [0.136, 0.255] | 39 |
| 高温 (>270K) | **0.046** | [0.017, 0.074] | 42 |

- **显著性**：低温 vs 高温 ΔEa 差异 t 检验 p<0.001，**低温限域效应显著强于高温**。
- **ΔEa(T) 线性**：斜率 ≈ -0.0021 eV/K，95%CI ≈ [-0.0029, -0.0013] eV/K。
- **结论**：低温限域效应强（ΔEa ≈ 0.20 eV）、高温弱（≈ 0.05 eV），与 S8 深度报告及“低温限域主导、高温趋同”一致；**已补充 bootstrap 95% CI 与显著性检验**，可直接用于论文 Results/Discussion。建议在 SI 中说明温区划分依据（230K/270K）。

### 1.2 S8 与 S60 模型质量（**均达标**）

- **S8 限域模型**：R² = 0.97，CV R² = 0.81，n = 121。拟合优度高，**满足发表要求**。
- **S60 基准模型**（已做稳健性改进）：R² = 0.90，**CV R² = 0.89 ± 0.03**，MAE = 0.069 eV，剔除异常值 3 个后 n = 59。泛化波动已明显降低，**可作稳健基线**；论文中可报告 R²、CV R²、MAE 及异常值剔除说明。

### 1.3 Meyer-Neldel 分析（**已实现**）

- S8：E_MN ≈ 0.020 eV，R² = 0.99，p<0.001；S8 高/低温分线：E_MN 约 0.027 eV（高温）、0.020 eV（低温）。
- S60：E_MN ≈ 0.021 eV，R² = 0.98，p<0.001。
- 与深度报告中 ln(σ₀)–Ea 补偿一致，**可支撑“机理–数据”闭环**；图表见 `phase3_results/meyer_neldel/`。

### 1.4 跨材料验证（**P2 已实现，可支撑 Discussion**）

- **定义**：α = Ea_实际 / Ea_预测（S8 模型预测非 S8 材料）；α≈1 表示迁移良好。
- **材料身份**（据 `数据说明_v2.txt` / 材料数据说明）：  
  - **S8**：海泡石 + H₃PO₄（主要研究材料）。**S12**：海泡石 + H₂O（纯水）。**S6**：海泡石 + 植酸。**S13**：膨润土 + 植酸。**S14**：埃洛石 + H₃PO₄。**S15**：高岭土 + 植酸。**S16**：膨润土 + H₃PO₄。**S95/S96/S97**：海泡石/膨润土/埃洛石 + H₂SO₄。
- **当前结果**（53 segments，8 种非 S8 材料；close 内 Phase 1 结果 + step1 全温区 fallback 覆盖 S15 等）：
  - **S14**（埃洛石+H₃PO₄）：mean(α)≈1.09，MAE≈0.13 eV，与 S8 最接近，迁移性最好。
  - **S16**（膨润土+H₃PO₄）：mean(α)≈0.82，略低估实测 Ea。
  - **S13**（膨润土+植酸）：mean(α)≈0.57，MAE≈0.17 eV，n=2；模型高估 Ea，与 S95–97 类似，可能因植酸+膨润土与 S8（海泡石+磷酸）差异大；**样本少，结论需谨慎**。
  - **S15**（高岭土+植酸）：n=1，mean(α)≈2.75，MAE≈0.40 eV；Ea 来自 Phase 1 全温区单段拟合（该样品无分段结果），模型低估实测 Ea；**仅 1 个 segment，结论需谨慎**。
  - **S6**（海泡石+植酸）：mean(α)≈1.98，std(α) 大，MAE≈0.28 eV，偏差较大，可能配方/限域与 S8 差异较大。
  - **S95/S96/S97**（硫酸体系）：mean(α)≈0.39–0.48，模型普遍高估 Ea，或反映不同粘土/酸体系的限域与化学差异。
  - **S12**（海泡石+H₂O，纯水）：n=2，mean(α)≈2.66，MAE≈0.33 eV；纯水体系与 S8（磷酸）差异大，仅作参考。
- **论文表述**：可写“S8 限域模型在部分材料（如 S14）上迁移较好（α≈1），在 S6、S13、S15 及 S95–97 上偏差较大，S15（高岭土+植酸）仅 1 个全温区拟合点、结论需谨慎；提示限域效应具有材料与酸体系依赖性。”
