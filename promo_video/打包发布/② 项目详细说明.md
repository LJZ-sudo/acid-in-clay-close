## 0. 项目定位与两条主线

**一句话**：这是一个**受物理 / 质控 / 声明（claim）约束、可审计的"智能体（Agent）驱动"材料发现项目**——
以"酸-黏土"（凹凸棒土 Attapulgite / AiCE 体系）质子导体为母体系，让 AI 在**数字世界**里
做证据约束的推理与优化，再到**物理世界**里真实合成与宽温阻抗（EIS）测量，全过程留痕、可复现、可追责、不过度声称。

项目当前实际分为**两条并行线**（理解这一点对把握"做到哪了"很关键）：

| 线 | 目标 | 现状 |
|---|---|---|
| **小论文线** | 用已有数据与审计结果，形成保守、可投稿的版本 | 已接近"冻结投稿基础"，余下主要是人工文字/格式/claim 措辞 |
| **v2 顶刊线** | 通过真实前瞻实验冲更高级别期刊 | 代码、门禁、协议、dry-run 已就绪；**真实前瞻实验与总控集成尚未完成** |

> 诚实定位：项目"不是什么都没做"，也"不是已经 Nature 子刊 ready"。它是一个**已跑通闭环、证据可审计、但仍在升级中**的真实科研系统。

## 1. 整体架构与数据流

### 1.1 它要跨越的那道缝

AI 在工业/科研发现里最难、也最值钱的一环，是跨越"**数字世界 ↔ 物理世界**"：

- **数字世界**：读文献、做推理、提候选、做优化——大多数 AI 项目停在这里（PPT 与仿真）。
- **物理世界**：真实合成、真实测量、真实失败——这里往往全靠人工、不可追溯、不可复现。

本项目用一个**可审计的闭环**把两端接起来，并以质子导体宽温电导为具体载体加以证明。

### 1.2 FactoryLab AIAF OS 标准闭环（八环节）

```
观测 → 理解 → 建模 → 仿真 → 授权 → 执行 → 反馈 → 学习 →（回到观测）
```

本项目把闭环真正接到了硬件与真实材料上。各环节与 FactoryLab 三件套
**Agent（智能体）/ Skill（技能）/ MEU（最小执行单元）** 的映射：

| 闭环环节 | 本项目里发生了什么 | Agent | Skill | MEU |
|---|---|---|---|---|
| 观测 | 宽温阻抗谱测量 + 实时质控 | 工况画像 Agent | 在线测量 Skill | 测试接口 MEU |
| 理解·建模 | 证据约束 + 文献知识侦察 | 文献专利 Agent | 知识检索 Skill | 仿真算力接口 |
| 仿真·授权 | 先仿真、再授权的执行门禁 | Critic / 认证 Agent | 审计追踪 Skill | 数字孪生沙箱 |
| 执行 | 真实合成 + 宽温测量（硬件） | 柔性试制 Agent | 配方下发 Skill | 协作机械臂 / 微型装配 MEU |
| 反馈·学习 | 数据回流 + AI 持续优化 | 实验设计 Agent | 贝叶斯 DoE Skill | 试验数据回放盒 |

- **Agent**：负责高层推理、规划、判断的"AI 大脑"。
- **Skill**：被标准化、可像 API 一样安全调用、输入输出受校验的"工业能力"。
- **MEU**：物理世界里真正动手的最小执行单元（测试夹具、机械臂、装配单元等）。

### 1.3 代码级数据流（真实落地的四个 Stage）

> Stage3 当前**不自动驱动** Stage1 实验；Stage1 主闭环是**单目标** BO（不是 MOBO）。详见各节。

## 2. 四个 Stage 详解（真实能力 + 边界）

### 2.1 Stage0 · EIS 测量与质控（QC）

从 EIS 原始/导出数据，对每个温度点产出：质量检查、Kramers–Kronig(KK) 一致性、
Rb 拟合、电导率、分段 Arrhenius 拟合，并打包为标准化"结果包"供后续读取。

- **电导率**：`电导率 = 厚度 / (Rb × 面积)`。
- **KK 一致性**：用于检验阻抗数据自洽性；当前是 **warning 模式（建议性）**，不是硬门禁。
- **DRT**：当前用 `max(G,0)` 近似，属 exploratory/screening，**不作机制证明**。
- **熔断规则**：质量检查若出现致命级，直接 `REJECTED_BY_QA`。

> 边界口径：可说"该点有/无 KK 警告、通过/未通过 QC"；**不能**说"KK 证明了机制正确"。

### 2.2 Stage1 · BO + LLM 优化闭环（项目最核心的"执行引擎"）

这是"数字 ⇌ 物理"反复迭代的所在。**这一节请重点看，video 的闭环幕全靠它。**

**配方空间与目标函数**（凹凸棒土 AiCE campaign）：

- 参数：`R`（酸量）∈ [0.0, 1.04]，`N`（中和度）∈ [0.5, 1.3]。
- 单目标分数：
  `combined_score = log10(室温电导率) − 3.0 × 高温段Eₐ − 0.5 × 低温退化项`
  含义：**奖励**室温电导率、**惩罚**高温势垒、**惩罚**低温退化。

**真实历史（8 条 trial，R/N 坐标）**：

```
T1 R=0.186 N=1.029   T2 R=0.35 N=0.95   T3 R=0.62 N=0.72   T4 R=0.50 N=0.50
T5 R=0.50  N=1.20    T6 R=0.64 N=0.58   T7 R=0.20 N=1.10   T8 R=0.50 N=0.90
```
（T1 制样条件与后续略不同，主协议用 T2–T8。）

**闭环怎么转**：读 Stage0 结果 → 写入 history → BO 建议下一组 R/N → LLM 策略护栏可修正建议
→ 安全校验 → 输出下一轮配方与闭环留痕。真实闭环 **6 轮**（2026-05-11 → 05-17），其中 **3 次** 有 LLM 修正。

**两个入口**：`run_optimization_loop.py`（完整闭环，real 模式会写库，参数无效则拒写——重要保护）；
`suggest_next.py`（只建议、不写库）。

**关键边界（写 video / 文档都要守）**：

- 主闭环是 **单目标贝叶斯优化（BayesianOptimizer）**；**MOBO（多目标）已实现但尚未接入主闭环**——
  不能说"MOBO 驱动了当前闭环"。
- LLM 护栏默认 temperature=0.2，不是完全确定性；BO 随机种子在某些设置下是动态的。
- v2 锁定包里的 R3/R4 是"锁定的建议 + 评审护栏"，**不是真实实验结果**；R4 的护栏是 agent/Codex 评审，**不是实时 LLM API 调用**。

### 2.3 Stage2 · 统计证据与 Stage3 种子

把 S8 输入 CSV 清洗（1081 → 1031 行）成证据单元、样品摘要、分段 Arrhenius，并生成
Stage3 的种子（`stage3_seed.json`）。

- 当前种子 `source_mode = retrospective`、`source_system = s8_reference`——
  即**回溯参考种子，不是新 v2 实验种子**。
- 因此 Stage3 能支持机制假设与候选生成，但**不能**直接证明"新的前瞻发现"。

### 2.4 Stage3 · 智能体管线（S03–S14）

这是"数字世界推理"的主体：一条**确定性、可审计的多智能体流水线**，而非"一个大模型直接吐答案"。

```
S03 证据构建 → S04 假设生成 → S05 机制文献侦察 → S06 机制仲裁
→ S06b 设计原则提取 → S07 描述符提取 → S08 材料文献侦察（真实 OpenAlex API）
→ S09 候选家族生成 → S10 确定性重排 → S12 前瞻登记（冻结）
→ S13 验证绑定 → S14 声明审计（守门） → S11 报告编译
```

**权威快照**（唯一可作"投稿级"引用的真实 LLM 跑数）：
`20260607_openrouter_publication_v2/`，`真实 LLM(live) · 关闭缓存 · temperature=0 · hybrid 文献`，
模型经 OpenRouter（gpt-5.2 / gpt-5.4）。S14 出具 `llm_transfer_candidate=PASS`。

**关键边界**：

- Stage3 默认是 `mock`；S09 默认走**确定性 D4 组合**（不是纯 LLM 自由发现），evidence-based S09 需显式开启。
- S10 最终分数由**确定性 candidate audit 重算**（LLM 只给定性理由），并做 200-seed 稳健性扰动。
- **agentic 层（记忆 / 自省 / 心跳）代码真实存在且有测试，但未接入主 orchestrator**——
  不能说"具备记忆/自省的自主 agent 实时驱动了全流程"。

## 3. 三大创新点（深入 + 证据 + 强度）

> 强度记号：A=证据充分可直接写；B+/B=可写但需加固或降级措辞。

### 3.1 创新点一 · 证据约束的迁移智能体（发现"新材料"）—— 强度 B+

**做了什么**：一个证据约束的迁移智能体，从"酸-黏土"母体系出发，在广义生物质 / 聚合物 / 黏土
文献池里推理，**选择并重组**出一批"生物聚合物–黏土"质子导体候选，并在动手实验之前**冻结**排名。

**真实冻结排名**（`run_id=stage3-1842d1f1ea`，`preregistered_at=2026-06-07T11:57:12Z`，
带 `registry_hash` 指纹，`live LLM · 关闭缓存 · 无泄漏 term_leakage=0 · temperature=0`）：

| 排名 | 候选材料 | 分数 | 在本项目中的角色 |
|---|---|---|---|
| 1 | 淀粉 / PVA / 有机改性凹凸棒土 / 磷酸 膜 | 0.883 | → 莲藕淀粉(LRS)：**正验证** |
| 2 | 壳聚糖 / 有机改性凹凸棒土 / 磷酸 复合膜 | 0.823 | → 壳聚糖(CHITO)：**边界验证** |
| 3 | 埃洛石纳米管 / 磷酸 / PVA 杂化膜 | 0.819 | 另一种黏土（列为未来工作） |
| 4 | PVA / 壳聚糖 / Nb₂O₅ / 磷酸 复合膜 | 0.738 | 未来工作 |
| 5 | PAAm-接枝-淀粉 / 磷酸 水凝胶 | 0.708 | 未来工作 |

**为什么有说服力**：实验真正验证的，正是 AI 冻结排名的**前二名**——
第 1 名（淀粉/LRS）做正验证、第 2 名（壳聚糖/CHITO）做边界验证，设计干净、无事后挑选。

**强度为 B+（不是 A）的原因（诚信边界）**：

- ✅ 智能体框架真、LLM 真（live、关缓存）、声明审计 PASS、排名稳定。
- ⚠ 形式上的"前瞻锚点"有一处是**重建的**（原始登记表曾在一次 cleanup 提交中被误删，
  由保留的文件名时间戳 + provenance 透明重建，前瞻余量较小）——这是"前瞻发现"叙事最脆弱的一环。
- ⚠ 声明审计把上限钉死在"**选择 / 重组**"，**禁止**"独立发明"。

### 3.2 创新点二 · 冷却韧性通路连续性描述符（发现"新机理"）—— 强度 B

**一句话**：为什么有的材料低温下还能导电？把候选做成膜、在宽温区间（室温降到约 −80 °C）测电导率 σ(T)，
得到一个**可迁移的判据（描述符）**，能把"低温还能导"和"低温就崩"的材料**干净地区分开**。

**真实数据（单位 S/cm；正/边界验证）**：

| 样品 | 角色 | 高温段势垒 Eₐ | 低温行为 |
|---|---|---|---|
| 莲藕淀粉 LRS（headline，0.022 cm） | 正验证 | **0.037 eV** | 平滑延伸到 −81 °C，仍导电 |
| 莲藕淀粉 LRS（重复，0.02 cm） | 正验证 | 0.042 eV | 重复性好 |
| 壳聚糖 CHITO（0.05 / 0.06 cm） | 边界验证 | —（转变/失效） | 约 −40 °C 附近电导率**骤降约 100×** |
| 玉米淀粉（对照） | 对照 | 0.216 eV | 普通行为 |

**势垒对标**（越低越易导电）：LRS **0.037** vs POP-2020 **0.039** vs MFM-300(Cr) **0.040** vs 母体系 AiCE 海泡石 **0.12**。
→ 措辞硬约束为"**逼近已报道最低势垒（record-level）**"，**禁用"世界纪录"**。

**质控**：全部 220 条阻抗谱经 KK 校验；修正一处复数阻抗符号约定 bug 后，
KK 警告由 **133 → 0**、中位残差 ≈0.007，**数据 KK 干净**。

**强度为 B（科学软肋最集中）的三处混淆（写作时须正面处理）**：

1. **厚度混淆**：低 Eₐ（0.037–0.042）只出现在 0.02–0.022 cm 薄膜；厚膜势垒高约 4×。
   → 应限定为"**可比薄膜几何下** LRS 势垒显著低"，不可直接说成"材料内禀"。
2. **headline 样品 QC 偏弱**：最低 Eₐ 的样品恰是 KK 警告较多的——主张应**限制在 KK 干净的高温窗口**。
3. **几何巧合**：headline 样品实测厚度 0.022 恰与某 fallback 值相同，需主动澄清是真实测量。

> 定位口径：描述符是**唯象的、可迁移的操作型判据**；机制以**文献锚定的假说**形式给出（无直接结构表征）。

### 3.3 创新点三 · 物理/QC 门控的 EIS 闭环执行 —— 强度 B+

**真实闭环**：6 轮（05-11 → 05-17），全 real，3 次 LLM 修正，每轮有配方指纹 + 时间戳。

**四道安全门禁**（高风险动作"先仿真、再授权、后执行"）：

1. 仅追加历史 · 操作绑定人工批准（hash 绑定，不可悄改）
2. 批准前禁写 · 测量与分析自动阻断
3. 提交门 + 质控校验 + 评分门
4. 先仿真 → 授权 → 执行 → 全量审计

**诚实的"非收敛/非发现"是力量来源，而非缺陷**：

- 本批闭环最优仍是初始点附近（`absolute_improvement=0`），即"执行成功、本轮未实现提升"——**如实报告**。
- 这套闭环卖的是**可信执行能力本身**（每步可控、可追溯、可优化），不是夸大单轮提升。

**强度 B+ 的边界**：主闭环单目标（MOBO 未接入）；执行引擎是 pre-lab 协议，目前无 result-like 文件（如实标 pending）。

## 4. 治理与可信（项目的灵魂）

与 FactoryLab 商业计划书"**先卖可验证能力，不卖黑箱自治**""**玻璃箱而非黑箱**"
"**分级自治 + 全量审计**"完全同频：

- **可追溯**：每个结论都能回到证据 / 原始数据 / 文献。
- **可复现**：固定随机性（temperature=0）、留指纹（hash）、可回放（append-only 记忆）。
- **可审计**：确定性的 claim audit 自动拦截过度声称（如把"独立发明"降级为"选择/重组"）；
  高风险动作全程留痕、可回滚、可追责。

> 这套"敢暴露边界、主动门控不确定性"的做法，在严肃科研与工业场景里是**加分项**而非减分项。

## 8. 名词小词典

- **EIS（电化学阻抗谱）**：施加不同频率微小电信号测阻抗，推算电导率等性质。
- **σ(T)**：电导率随温度的变化；本项目关心"降温时它怎么变"。
- **Eₐ（活化能/势垒）**：离子"跳一步"要翻过的能量坎，越低越易导电。
- **BO（贝叶斯优化）**：少做实验、聪明选点，自动建议下一个最值得试的配方。
- **MOBO（多目标贝叶斯优化）**：同时优化多个目标（如高电导+低势垒+低温稳定），求 Pareto 前沿；**本项目已实现、尚未接入主闭环**。
- **R / N**：本项目的配方变量（酸量 / 中和度）。
- **LLM 护栏（guardrail）**：用大语言模型对优化建议做安全/合理性把关与修正。
- **Kramers–Kronig（KK）一致性**：检验阻抗数据自洽性的物理判据，用于剔除不可信谱。
- **claim audit（声明审计）**：用确定性规则审查 AI 措辞，自动拦截过度声称。
- **前瞻冻结（prospective freeze）**：动手实验**之前**先锁死预测/排名并留指纹，事后不可改。
- **MEU（最小执行单元）**：物理世界里真正动手的最小单元（夹具/机械臂/装配单元）。
