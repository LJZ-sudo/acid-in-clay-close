# 宝塔面板部署演示站点（factorylab.online）

服务器：阿里云轻量 + 宝塔 + Apache
站点根目录：`/www/wwwroot/factorylab.online`

## 你要上传的东西
`promo_video\上云包_演示网站.zip`（约 108MB，里面是 `index.html` + `assets/` + `.htaccess`）

## 步骤

1. **确认域名解析**（多半你已做）
   - 在域名 DNS 处加一条 A 记录：`factorylab.online` → `47.242.209.157`（你的服务器公网 IP）。
   - 能用域名打开宝塔默认页，就说明解析 OK。

2. **上传并解压**
   - 宝塔左侧「文件」→ 进入 `/www/wwwroot/factorylab.online`。
   - 把默认的 `index.html`（917B 那个宝塔默认页）先删掉。
   - 点「上传」，上传 `上云包_演示网站.zip`（视频大，按你的上行带宽耐心等）。
   - 上传完，右键该 zip →「解压」到当前目录。遇到同名 `.htaccess` 选「覆盖」。
   - ✅ 解压后根目录应有：`index.html`、`assets/`（里面是视频和配音）、`.htaccess`。
   - ❌ 注意别解压成 `.../factorylab.online/dist/index.html` 这种多一层的；应直接在站点根目录。

3. **配置文件：基本不用改**
   - 宝塔的 Apache 主配置里 `DirectoryIndex` 已含 `index.html`，会自动当首页。
   - MIME / 缓存 / 视频拖动这些，都由我们放进去的 `.htaccess` 处理好了，不用手动改主配置。

4. **访问**
   - 打开 `http://factorylab.online/` → 应看到「▶ 播放全片（含配音）」按钮，点一下从头连贯播放。

5. **强烈建议：开 HTTPS（宝塔一键，免费）**
   - 站点「设置 → SSL → Let's Encrypt」→ 选中域名 → 申请 → 开启「强制 HTTPS」。
   - 香港服务器免备案，可直接签发。开完用 `https://factorylab.online/` 访问，不再提示"不安全"，微信里也能正常打开。

## 关于声音：能正常播放
- 浏览器规定"网页不点一下不让自动出声"，所以**打开页面是先看到 ▶ 播放按钮**，点它之后配音和硬件视频原声都会正常播放（http 也行）。
- 这是正常现象，不是 bug；别期待"打开就自动出声"。

## 排错
| 现象 | 解决 |
|---|---|
| 打开还是宝塔默认页 | 默认 `index.html` 没删/没被覆盖，删掉旧的、确认我们的 index.html 在根目录 |
| 页面打开但视频/配音加载不出 | assets 没传全或多了一层目录，重新确认根目录结构 |
| 403 / 无权限 | 在宝塔把该目录所有者设为 `www`，权限 755/644 |
| 改了内容不更新 | 浏览器缓存，访问时按 Ctrl+Shift+R |

## 以后更新内容
1. 本地 `npm run build` 重新生成 `dist`。
2. 重新打包或直接把新的 `index.html` + `assets` 覆盖上传到站点根目录。
3. 访问时 Ctrl+Shift+R 强制刷新。
