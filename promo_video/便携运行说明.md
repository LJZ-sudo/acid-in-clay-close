# 在别的电脑上展示 —— 三种方式

> 这是个 Vite/React 工程，**不能直接双击 index.html 打开**（ES 模块 + 媒体需要本地服务器）。
> 拷过去之前，先把最终的硬件录屏放到 `demo_frontend/src/assets/hardware_demo.mp4`，**再重新打包**（否则第 5 幕是占位图）。
> ⚠️ 不要拷 `node_modules`（几百 MB 且与系统相关）。

---

## 方式一：录成 mp4 成片（最省事、零依赖，推荐用于"纯展示"）

在**这台已经配好**的电脑上：
1. `cd demo_frontend && npm run dev`
2. 浏览器打开 `http://127.0.0.1:5274/?autoplay=1`（全屏 F11）
3. 用录屏软件（OBS / 系统录屏）录制，**务必勾选"系统声音/扬声器"**，配音就录进去了
4. 导出一个 mp4

→ 把这个 mp4 拷到任何电脑，双击就能放，**不需要 Node、不需要 Python、不需要联网**。

## 方式二：拷打包好的静态成品 `dist/`（要现场交互/实时演示）

1. 先在这台电脑构建：`cd demo_frontend && npm run build` → 生成 `demo_frontend/dist/`
2. 把 **`demo_frontend/dist/`** 和 **`demo_frontend/运行演示.bat`** 一起拷到目标电脑（放在同一层，bat 在 dist 的上一级）
3. 目标电脑双击 **`运行演示.bat`** → 自动起本地服务器并打开浏览器（带自动播放）

> 目标电脑需要 **Python 或 Node**（二选一，都很小）。bat 会自动检测：有 Python 用 `python -m http.server`，有 Node 用 `npx serve`。
> 手动等价命令（在 dist 上一级目录）：`python -m http.server 5273 --directory dist`，然后浏览器开 `http://127.0.0.1:5273/?autoplay=1`。

## 方式三：拷源码重新跑（要改文案/数据/重新打包）

1. 拷 `demo_frontend/` 整个目录，但**删掉 `node_modules`**
2. 目标电脑需装 **Node 18+**，然后：
   ```
   cd demo_frontend
   npm install          # 需要联网
   npm run dev          # 开发预览 http://127.0.0.1:5273/
   npm run build        # 重新打包出 dist/
   ```

---

## 常用地址与操作
- 自动播放（录屏用）：`?autoplay=1`
- 跳到第 N 幕：`?scene=N`（1–8）
- 静音录画面：`?mute=1`
- 键盘：空格 播放/暂停 · ← / → 切幕 · `r` 重播 · `m` 静音
- 改配音：编辑 `demo_frontend/scripts/gen_audio.py` 的 `NARRATION`，再 `python scripts/gen_audio.py`（须与 `App.jsx` 的 `SCENES[].narration` 一致），然后重新 `npm run build`
