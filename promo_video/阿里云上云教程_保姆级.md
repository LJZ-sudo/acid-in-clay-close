# 演示网站上阿里云 OSS —— 保姆级教程（香港地域 · 免备案）

> 目标：把本地的 `demo_frontend\dist\`（或 `上云包_演示网站.zip` 解压后的内容）放到阿里云，
> 得到一个 `https://你的域名/` 链接，任何人点开就能看到现在这个演示页（含配音、含硬件视频）。
>
> 路线说明：用**中国香港**地域 + **自己的域名**。香港地域**不需要 ICP 备案**，
> 当天就能上线；域名只需做一次很快的「域名实名认证」（不是备案）。

---

## 一次性准备（约 10 分钟）

1. **注册并登录阿里云**：https://www.aliyun.com ，完成「个人实名认证」（支付宝刷脸即可）。
2. **买一个域名**（阿里云「域名」频道）：
   - 想省钱：选 `.top` / `.xyz`（首年常 9–29 元）；想正式：选 `.com`（约 60–90 元/年）。
   - 买完后到「域名控制台」给它做 **域名实名认证**（上传身份证，几分钟~几小时通过）。
   - ⚠️ 这一步叫「实名认证」，**几分钟搞定**；它**不是** ICP 备案（备案才要 1–2 周，香港地域用不到）。

---

## 第 1 步：开通 OSS、建桶（Bucket）

1. 阿里云控制台搜索「**对象存储 OSS**」→ 开通（按量付费，几乎没费用）。
2. 点「**创建 Bucket**」，按下面填：
   - **Bucket 名称**：全小写字母/数字/短横线，全网唯一，例如 `factorylab-demo-2026`。
   - **地域（Region）**：选「**中国（香港）**」← 关键，免备案。
   - **存储类型**：标准存储。
   - **读写权限**：选「**公共读**」（让别人能打开网页；不要选私有）。
   - 其它全部默认 → 创建。

## 第 2 步：把网站文件传上去

要传的是 `demo_frontend\dist\` 里的 **`index.html`** 和 **`assets` 文件夹**（assets 里有视频和配音）。
有视频较大（约 108MB），建议用阿里云官方图形客户端 **ossbrowser**（断点续传更稳）：

1. 下载 ossbrowser（搜「ossbrowser 下载」进阿里云官网）→ 安装打开。
2. 登录：用 **AccessKey**（控制台右上角头像 → 「AccessKey 管理」→ 创建一个，复制 ID 和 Secret 填进 ossbrowser）。
3. 进入你刚建的 Bucket，把本地 `dist` 里的 **`index.html` 和 `assets` 文件夹**，
   **直接拖到 Bucket 的根目录**。
   - ✅ 传完后，Bucket 根目录里应能直接看到 `index.html` 和 `assets/`。
   - ❌ 不要把整个 `dist` 文件夹拖进去（那样会变成 `dist/index.html`，多一层就打不开了）。

> 不想装 ossbrowser 也行：OSS 控制台「文件管理 → 上传文件 / 上传文件夹」也能传，网络好就行。

## 第 3 步：开启静态网站托管

1. 进入 Bucket → 左侧「**数据管理 → 静态页面**」（有的版本在「基础设置」里）。
2. **默认首页**填 `index.html`；**默认 404 页**也填 `index.html`；保存。

## 第 4 步：绑定你的域名（关键一步，绕过"强制下载"）

> 不绑域名、直接用 OSS 自带网址打开 `index.html` 会被强制下载、看不到页面。绑了自己的域名就正常显示。

1. Bucket → 左侧「**传输管理 → 域名管理**」→「**绑定域名**」。
2. 填你要用的网址，例如 `demo.你的域名.com`（子域名）或直接 `你的域名.com`。
3. 因为域名也在阿里云，勾选「**自动添加 CNAME 记录**」→ 确定。
4. 等 5–30 分钟让解析生效。香港地域**无需备案**，这一步不会拦你。

## 第 5 步（强烈建议）：配 HTTPS，让链接更"正规"、能在微信里打开

只用 http 的话，浏览器会显示"不安全"，微信里还可能打不开视频/音频。配一张**免费证书**即可：

1. 阿里云搜索「**数字证书管理服务（SSL 证书）**」→ 申请一张**免费 DV 单域名证书**，绑定你上面用的域名，按提示验证（DNS 验证，几分钟）。
2. 回到 OSS → Bucket →「传输管理 → 域名管理」→ 找到你绑定的域名 →「**证书托管**」→ 选刚申请的证书 → 开启。
3. 完成后即可用 `https://你的域名/` 访问。

## 第 6 步：拿到链接，发出去

- 打开 `https://你的域名/`（或 `http://你的域名/`）→ 应看到演示首页的「▶ 播放全片」按钮。
- 点一下就从头连贯播放（含配音）。把这个网址发给老师/投资人即可。

## 常见问题（对症排查）

| 现象 | 原因 | 解决 |
|---|---|---|
| 打开网址变成**下载** `index.html` | 用了 OSS 自带网址，没走自己的域名 | 必须用第 4 步绑定的**自己的域名**访问 |
| 打开是 **403 / AccessDenied** | Bucket 不是公共读 | Bucket 权限改「公共读」 |
| 页面打开了但**视频/配音加载不出** | assets 没传全，或多套了一层目录 | 确认根目录是 `index.html` + `assets/`，重传 assets |
| 视频点开是**下载**而不是播放 | 一般不影响：网页里的视频是内嵌加载，正常播放 | 若直接访问视频网址才会下载，属正常 |
| 微信里打不开 / 提示不安全 | 没配 HTTPS | 完成第 5 步配证书 |
| 页面是**旧版** | 浏览器缓存 | 重新上传后，访问时按 Ctrl+Shift+R 强制刷新 |

## 费用心里有数
- 域名：约 ¥9–90 / 年（按后缀）。
- OSS：存储 110MB + 少量访问流量，**每月通常几毛到几块钱**（按量付费）。
- SSL 证书：免费 DV 证书 ¥0。
- 香港地域：无需备案、无备案费。

## 以后想更新内容怎么办？
1. 在本地改完，重新 `npm run build` 生成新的 `dist`。
2. 用 ossbrowser 把新的 `index.html` + `assets` **覆盖**上传到 Bucket 根目录。
3. 访问时 Ctrl+Shift+R 强制刷新即可看到新版。
