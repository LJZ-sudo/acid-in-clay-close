# Phase C Experiment Protocol

**Date:** 2026-06-02
**Project:** acid-in-clay-close
**Status:** protocol only; no real result; v2 remains HOLD
**Scope:** define the real-lab Phase C design, evidence gates, and failure handling needed before any v2 claim upgrade.

This protocol is the bridge from the completed Phase A/B software work to real v2 experiments. It does not modify the frozen small-paper package, does not generate experimental data, and does not authorize any claim. Phase C starts only after a human signs the pre-lab checklist.

## Non-Negotiable Boundaries

- Do not edit `three_pillars/**` (round templates and evidence are append-only).
- Do not rewrite existing raw data or protected evidence.
- Do not write v2 results into the current small-paper submission package.
- Do not enable CHI automation unless the separate macro/dummy-cell/preflight evidence gate is complete.
- Do not use EIS language such as "EIS proves mechanism" or "EIS confirms mechanism".
- Do not claim "BO+LLM discovered LRS", "v2 Pareto achieved", "global optimum", "world record", or "Nature Communications ready".
- All Phase C data must enter a new append-only v2 evidence area with hashes and human approvals before it can inform a claim.

## Phase C Objective

Phase C tests whether the v2 system can support a separate, upgraded paper by adding real, reproducible, auditable evidence. The target is not "better code"; the target is a new evidence layer:

- conductivity reproducibility from independent preparations;
- low-temperature EIS with manual Rb QC and numeric KK caveats;
- hysteresis / heating-back evidence for pathway continuity;
- leakage exclusion by DC polarization or equivalent validated method;
- structural, thermal, and spectroscopic support for any mechanism wording;
- a new freeze and claim map after the real evidence exists.

Until those items exist, v2 remains HOLD.

## Candidate Strategy

The experiment should use a small, pre-registered matrix. Do not synthesize every candidate the intelligence layer can produce. Phase C should prioritize interpretable evidence over breadth.

Use `phase_c_sample_matrix.csv` in this folder as the starting template. A human must fill exact recipes, masses, geometry, and preparation notes before lab work.

Recommended minimum groups:

| Group | Purpose | Minimum independent preparations | Claim role |
|---|---:|---:|---|
| LRS-positive branch | Test reproducible low-temperature conductivity | 3 | conductivity claim candidate |
| CHITO / boundary branch | Test contrast and possible path collapse | 2 to 3 | boundary / mechanism support |
| Matrix or polymer control | Separate matrix effect from acid/clay effect | 1 to 2 | control only |
| Acid / clay / blank controls | Check leakage, background, and fitting artefacts | 1 to 2 | QC only |
| S09 evidence-based v2 candidate | Prospective candidate generated by opt-in S09 | 1 to 2 initial screens, then 3 if promising | v2 hypothesis, not claim until repeated |

If resources are limited, run LRS-positive branch plus one CHITO boundary branch first. If the LRS-positive branch fails reproducibility, do not proceed to broad candidate expansion.

## Measurement Plan

### C1. Sample Preparation

For each sample:

- assign a unique Phase C sample id before synthesis;
- record exact composition, batch, solvent/water content if relevant, drying or conditioning history, film/pellet geometry, electrode method, and operator;
- record whether the sample is a positive branch, boundary branch, S09 v2 candidate, or control;
- never reuse a sample id after a failed preparation.

Independent preparations must be independent physical preparations, not repeated measurements of one specimen.

### C2. EIS Conductivity Series

For each main candidate and control:

- measure a pre-registered temperature sequence covering room temperature and low-temperature anchors;
- include cooling and, for hysteresis samples, heating-back on the same or matched specimen;
- save raw EIS exports unchanged;
- record exact instrument settings and all failed or noisy spectra;
- do not delete spectra that fail KK or fitting QC.

The exact temperature grid must be chosen before acquisition. A practical grid should include warm anchors, the key low-temperature region, and at least one cold-tail point if the instrument can stabilize. Cold-tail points are screening unless QC is strong.

### C3. Manual Rb QC

For every spectrum used in a conductivity number:

- record selected Rb method and reviewer;
- record thickness and area with units;
- record whether Rb came from intercept, fit, or manual selection;
- record rejection reason for spectra not used;
- classify each point as `main-text candidate`, `supplementary candidate`, `screening only`, or `not publishable yet`.

Do not promote an automated fit to main-text status without manual review.

### C4. KK / EIS Validity

For every EIS point:

- compute numeric KK residual where possible;
- store `kk_mu_median`, `kk_passed`, and `kk_threshold`;
- if `kk_mu_median > 0.05`, keep the data but require a bounded caveat;
- if no numeric KK is available, label the point as legacy / bounded-caveat only;
- never use KK as mechanism evidence. KK is QC only.

### C5. Hysteresis / Heating-Back

For the LRS-positive branch and at least one boundary branch:

- run cooling and heating-back sequences;
- compare conductivity and Rb trends at matched temperatures;
- document irreversible drift, electrode changes, or sample damage;
- if heating-back is missing, do not claim pathway continuity or reversibility.

### C6. Leakage Exclusion

Run DC polarization or an equivalent pre-approved leakage test for samples that may support a low-temperature conductivity claim.

Required output:

- raw current/time trace or equivalent;
- method note with bias, duration, electrode configuration, and stabilization criterion;
- verdict: leakage excluded / bounded caveat / failed.

If leakage exclusion fails or is absent, the sample cannot support a headline conductivity claim.

### C7. Structural / Thermal / Spectroscopic Support

For mechanism wording beyond a boundary observation, collect convergent evidence:

- DSC or equivalent thermal transition evidence;
- FTIR or Raman for acid/polymer/hydrogen-bond state;
- SEM/EDS or equivalent morphology/composition evidence if claiming confinement or dispersion.

EIS trends may motivate the mechanism, but they do not prove it. A mechanism claim requires at least hysteresis plus one thermal/spectroscopic line, preferably with microscopy or composition support.

## Evidence Gates

| Gate | Required artifact | Pass condition | If failed |
|---|---|---|---|
| G1 human approval | signed approval note | signed before lab work | no Phase C start |
| G2 append-only raw intake | hash chain / intake log | no overwrite, all raw files present | data cannot enter v2 claim map |
| G3 manual Rb QC | Rb workbook / JSON | reviewer, method, units, geometry complete | point downgraded or rejected |
| G4 numeric KK | KK residual summary | `kk_mu_median <= 0.05` or bounded caveat | no uncaveated EIS claim |
| G5 leakage exclusion | DC polarization evidence | leakage excluded | no headline conductivity claim |
| G6 reproducibility | independent prep summary | >=3 consistent positive-branch preps | no reproducibility claim |
| G7 hysteresis | cooling/heating-back comparison | continuity or bounded failure documented | no reversibility / pathway claim |
| G8 mechanism support | DSC/FTIR/Raman/SEM evidence | convergent non-EIS support | mechanism downgraded |
| G9 claim gate | S14 / v2 claim gate | forbidden wording absent | no manuscript-bound v2 claim |
| G10 new freeze | frozen manifest + claim map | all evidence hash-bound | v2 remains HOLD |

## Claim Unlock Ladder

Use this ladder after data collection:

| Evidence state | Allowed statement |
|---|---|
| No Phase C data | v2 remains HOLD; software dry-run only |
| EIS data without KK/Rb/leakage | screening only |
| EIS + manual Rb + KK caveats | bounded conductivity observation |
| >=3 independent positive preps + Rb/KK/leakage | reproducible conductivity claim candidate |
| conductivity + hysteresis | pathway-continuity hypothesis supported, not proven |
| conductivity + hysteresis + DSC/FTIR/Raman/SEM | mechanism claim candidate, still bounded |
| all above + new freeze + claim gate PASS | v2 claim may be considered for manuscript |

## Failure Handling

Negative results are part of Phase C. Do not hide them.

- Failed preparation: keep sample id and failure reason.
- Failed KK: keep spectrum, downgrade claim level.
- Failed leakage exclusion: no headline conductivity claim.
- Failed repeatability: no reproducibility claim; consider mechanism-only or boundary-only framing.
- Failed CHITO contrast: do not claim path collapse; treat as boundary inconclusive.
- Candidate underperforms: retain as prospective execution evidence, not as discovery success.

Only after this package exists should Stage3 be rerun against real Phase C evidence.

## Stop Conditions

Stop Phase C expansion if any condition occurs:

- protected small-paper evidence is accidentally modified;
- raw data intake is not append-only;
- sample ids or recipes are ambiguous;
- manual Rb QC is missing for intended headline points;
- leakage exclusion fails for all positive candidates;
- repeated preparations do not reproduce the signal;
- claim wording starts using EIS as mechanism proof.
