# Tier S 手稿草稿(脊柱优先)2026-06-22

> **定位**:把 M0–M2(分析硬化)与 M5 三个 Demo(三大 Agent 创新)缝成**一条主线**。
> **脊柱(全文唯一主线)**:
> \[ \boxed{\text{可信自治上限} \;=\; \min(\underbrace{\text{复现能力}}_{R},\ \underbrace{\text{可辨识能力}}_{I},\ \underbrace{\text{执行可靠性}}_{X},\ \underbrace{\text{证据治理能力}}_{G})} \]
> 一个自驱动实验室能"可信地发现并声称"什么,被这四项**可测量能力的最小值**封顶。本文把 R/I/X/G 四项
> 都做成**可测量、可复算、代码强制**的对象,并用一个真实材料案例(凹凸棒土/生物聚合物质子导体的亚零度
> 传导转变)作为"同时撞上这四条边界"的检验场。
>
> **诚实边界(贯穿全文,不可删)**:三大 Agent 创新(执行可靠性 X、证据治理 G)目前是**运行时实现 +
> 软件演示通过**(故障注入 / 历史失效事件 / 合同认证),**尚未在真机湿实验闭环端到端联调**;材料发现为
> **EIS-only,机理主张硬封顶 C4**;线 B 闭环为诚实 null。

---

## 0. 一句话卖点(给编辑/审稿人)

> 我们不声称"AI 发现了更好的材料"。我们证明:**在只有阻抗数据、样本昂贵、结构不可见的真实湿实验里,
> 一个自驱动 Agent 能可信地声称什么,由四项可测量能力的最小值决定**——并把这四项做成可复算、代码强制的
> 运行时(复现地板↓、可辨识天花板↑、三重提交执行闸、反事实证据治理),用一个亚零度质子传导案例当检验场。
> 核心指标不是电导率,而是 **错误认知提交率 / 反事实记忆失真 / 未认证自主执行风险**。

## 1. Title / Abstract(草)

**Title(候选)**:
- *Credibility-bounded autonomous discovery: a min-of-four capability limit for evidence-limited self-driving labs*
- 备选:*What an honest self-driving lab can claim: reproducibility, identifiability, execution and governance as a joint bound*

**Abstract(结构化草稿,~180 词)**:
1. 背景:SDL 评价多看自主度/吞吐/优化效率,缺"物理动作—有效测量—科学主张"的可信度封顶。
2. 命题:可信自治上限 = min(复现 R, 可辨识 I, 执行可靠 X, 证据治理 G);四项缺一即整体被拉低。
3. 方法:把四项做成可测量+代码强制——复现地板的层级方差分解、设计条件下的实践不可辨识性、三重提交
   物理信念态 Harness、反事实证明携带记忆 + 可认证 Skill 的双账户治理。
4. 案例:EIS-only 质子导体亚零度传导转变——它**通过** R(方法不变 + 低假阳性)、被 I **封顶**(三律不可辨识→C4)、
   在 X/G 下只接纳合格证据。
5. 结果:闭环诚实 null(top 候选在地板内不可区分,P≈0.45);LLM 安全修正可被确定性规则替代;
   三大治理创新软件演示通过(错误认知提交率/反事实记忆失真/未认证执行风险均达标)。
6. 意义:给"表征受限自驱动发现"一个可证伪、可复算的可信度框架。

## 2. Introduction(要点)

- **问题**:自驱动实验室在昂贵/不可逆/部分可观测的湿实验里,容易把"软件 success"当"科学成功"。现有评价
  (自主度/吞吐/优化效率)不回答"**这个发现可信到什么程度、能声称到哪一级**"。
- **空白**:NIST 明确材料自驱动尚无标准化生态;LAP 等协议提出仪器锁/单位/校准语义但仍 v0.1、无大规模实证;
  缺"物理动作—有效测量—科学主张"的**形式化提交**与**可信度封顶**。
- **本文贡献(四项,对应脊柱)**:
  1. **R 复现能力**:把"复现地板"从一个数字升级为**带适用域(scope)的层级方差模型**,并把"候选差<地板"
     的二值判定改成概率;量化分析管线自身的**假发现率(FPR)**。
  2. **I 可辨识能力**:把"三传导律拟合接近"升级为**设计条件下的实践不可辨识性**(模型混淆矩阵)+ 断点
     的 bootstrap 置信区间;据此把机理主张**硬封顶 C4**。
  3. **X 执行可靠性**:**三重提交物理信念态 Harness**(物理/计量/认知提交),不变量"无效测量不入 BO";
     超时先核对、禁盲目重试。
  4. **G 证据治理能力**:**反事实证明携带记忆**(证据失效自动传播、独立支持链存活)+ **可认证 Skill +
     双账户认知博弈**(说得准≠拿到执行权)。
- **统一命题**:R/I/X/G 任一薄弱都会把"可信自治"拉低 → 故取 min。本文把四项都做成可复算对象,并在一个
  真实案例上展示它们如何**同时**约束一个发现。

## 3. Results(按脊柱四项组织 —— 这是缝线的关键)

> 写作铁律:每一小节先给"该能力如何被测量",再给"案例如何撞上这条边界",最后给"代码/产物锚点(可复算)"。

### 3.1 案例与四条边界一览(Fig 1 总览 + Table 1)
- 案例:藕粉(LRS)/淀粉/壳聚糖-黏土-磷酸 + 凹凸棒土;变温阻抗 +25~−90℃;描述符 σ_RT / Ea / 低温传导区间转变。
- Table 1:四项能力 × {如何测量, 案例表现, 结论上限}。把"可信自治上限=min(R,I,X,G)"实例化。

### 3.2 R — 复现能力(决定"多小的提升不可信")
- **层级方差分解**(`stage0_v2/repro_floor_variance.py`,M2-1/G8):between-specimen log10σ 地板 **0.252 dex
  (CI [0.13,0.32], n=7)**;CROSS_BATCH(4月薄片 vs 6月标准化)均值差 **0.34 dex**(厚度/接触混杂,诚实标注)。
- **分析不确定度 ≪ 复现地板**(`conductivity_uncertainty.py`,M2-2):room-T 方法间 spread ~5e-4 dex,
  combined_score 分析不确定度 ~0.058 ≪ 0.252 → 限制来自制备/几何而非分析。
- **管线假发现率**(`synthetic_validation.py`,M1-2):无转变平滑谱跑全链,6.15_merged FPR=**0.06**(超过假阳性
  地板);较弱单数据集 0.14–0.24 **诚实并列**;注入断点检出率=100%。
- **案例撞边界**:线 B top-2 候选 combined_score 差 0.217 → 在地板下 **P(不可区分)=0.45**(诚实 null 的概率版)。

### 3.3 I — 可辨识能力(决定"多强的机制主张不可支持")
- **Rb 方法不变性**(`rb_method_invariance.py`,M1-1/G2):四法并行 + 可信集一致性;主力 LRS risk=low,
  转变跨固定策略一致(断点跨度 1–5 K)→ 转变**不是 Rb 温区路由伪影**。
- **断点不确定度**(`breakpoint_uncertainty.py`,M1-5):残差 bootstrap,4/5 关键 LRS p_break=1.00,
  断点 CI ≈ **−34~−32℃** → robust_empirical_transition。
- **设计条件下实践不可辨识性**(`identifiability_v2.py`,M1-7):Arrhenius/VTF/Mott 模型混淆矩阵,正确判别仅
  **0.55–0.73**(随机 0.33)→ design-conditional partial non-identifiability。
- **案例撞边界**:转变在 R 下稳健,但机理在 I 下**不可唯一辨识** → 主张**硬封顶 C4**(只到"机理一致/相容",
  不声称结构/因果)。

### 3.4 X — 执行可靠性(决定"哪些测量有资格成为证据")
- **三重提交 Harness**(`scientific_harness/`,M5-A):物理提交 C_P(发生/未发生/部分/未知/重建)→ 计量提交
  C_M(复用 M1-4 证据准入:QA/KK/Rb)→ 认知提交 C_E;不变量 **¬C_E ⇒ 不入 {BO, 主张, 记忆}**;
  超时**先核对、禁盲目重试**(`reconciler`);SHA 事件链可验。
- **🅰️ Demo A**(故障注入,纯软件):6 场景(超时/确认丢失/未平衡/校准过期/KK失败)→ **盲目重试=0、
  无效进 BO=0、确认丢失正确重建为 RECONSTRUCTED、事件链有效**。
- **案例撞边界**:确认丢失但文件已生成 → Harness 经核对**重建**为已发生(不丢数据、不盲目重测);
  温度未平衡/校准过期 → C_M INVALID → 该测量**进不了 BO**(只入诊断库)。

### 3.5 G — 证据治理能力(决定"失效如何传播、什么能复用执行")
- **反事实证明携带记忆**(`scientific_memory/`,M5-B):SQLite 证据超图 + 四值逻辑(UNKNOWN/SUPPORTED/
  REFUTED/CONTESTED,禁最后写入者胜出)+ 最小支持集 + 失效传播。
  **🅱️ Demo B(两真实历史失效事件)**:KK 符号 bug → 主张 CONTESTED→REFUTED + 旧决策 AFFECTED;
  ECE 随机划分泄漏(0.05)→ 主张 SUPPORTED→UNKNOWN、诚实 0.13 存活;转变主张经**独立数据集**存活。
  验收:**失效证据被检索率=0 / 下游主张自动重算=100% / 独立支持链存活=100%**。
- **可认证 Skill + 双账户**(`scientific_skills/`,M5-C):6 Skill 合同/证书/生命周期,控制面**只调 VALIDATED**;
  组合需 post⊨pre;**认知账户(Brier)与执行账户(风险清算)分离 → "说得准"不直接换"执行权"**。
  **🅲 Demo C**:证书外/未认证拒绝、断链被拒、双账户分离、过度自信被 Brier 惩罚、**risk-coverage
  0.42@risk≤0.10**(替代恒 HOLD 的 0)。
- **案例撞边界**:线 B LLM 把 raw R=0.0285 修正到 0.28 —— `policy_ablation.py`(M2-4/G4)对照 5 基线显示
  **确定性投影/规则可复制该方向 → LLM 安全价值"可替代"**;故治理把 LLM 定位为"有界策略顾问",执行权由
  风险清算独立决定。

### 3.6 综合:四项的 min 就是这篇能诚实声称的上限
- R 让"亚零度转变"站得住(方法不变 + 低 FPR + 断点 CI);I 把它封顶 C4;X 保证只有合格测量进入证据;
  G 保证失效可传播、执行权不被自信骗取。**任何一项薄弱都会把整体可信度拉低** → 这就是 min 的含义,也是
  本文的统一结论。

## 4. Methods(要点 + 代码锚点)

- **数据**:7×LRS / 4×淀粉 / 2×壳聚糖 / 10×凹凸棒土(line B);全 EIS,无结构表征;DRT 本数据 R²<0 不作证据。
- **R 方法**:层级方差 `y~t_ν(μ,√(s²+τ²))`;概率化可区分 `P(|Δ|>δ)`;合成无转变全管线 FPR。
- **I 方法**:Rb 四法可信集一致性;谱级残差 bootstrap 断点 CI;三律模型混淆矩阵 + AICc。
- **X 方法**:三重提交状态机 + reconciler;不变量 `¬C_E⇒¬updateModel`、`timeout⇒¬retry U reconciled`;
  C_M/C_E 复用证据准入。
- **G 方法**:证据超图四值逻辑 + 最小支持集 + 失效传播;Skill 合同/证书 + 组合 post⊨pre;双账户(严格适当
  评分 Brier/log-loss vs 风险清算);risk-coverage 选择性预测。
- **可复算**:所有 v2 产物带 provenance(分析版本 + config sha256 + git commit);冻结清单锚定 legacy;
  三个 Demo 报告在 `_new_data_analysis/scientific_{memory,harness,skills}/`。

## 5. Discussion / Limitations(诚实,务必保留)

1. **三大创新为软件演示**:Demo A/B/C 证明运行时语义可用,但**未在真机闭环端到端联调**(待 M3/M4 实验台,
   见真机联调方案)。写作表述"运行时已实现 + 软件演示通过 + 待真机集成"。
2. **EIS-only → C4 封顶**:机理不可声称结构/因果。
3. **线 B 诚实 null**:闭环未越地板;LLM 安全价值可被确定性规则替代(不写"LLM 负责安全")。
4. **复现地板是代理**:线 B 现用 LRS 代理地板;G1 同配方重复将给 `LINE_B_LOCAL_DIRECT` 直接地板。
5. **框架风险**:若四条线未被脊柱真正缝起 → 可能被视为拼凑;故全文以 min(R,I,X,G) 为唯一主线。
