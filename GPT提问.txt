# 一、把两种模式统一成同一个科学决策问题

建议不要把迁移发现和闭环优化做成两套割裂系统，而是共享一个“部分可观测科学决策模型”。

真实但不可见的材料状态为：

[
z={\text{水合状态、酸分布、界面状态、微结构、老化状态、接触状态}}
]

系统能观察到的是：

[
y={Z(\omega,T),\text{热史、湿度、批次、几何、工艺、失败标签}}
]

智能体维护的不是一个“确定答案”，而是对潜在状态和竞争假设的信念分布：

[
b(z,H\mid D)
]

下一实验统一按以下效用选择：

[
a^*=\arg\max_a
\left[
\lambda,\mathrm{EIG}(H;Y\mid a,D)
+(1-\lambda),\mathbb{E}[\Delta HV]
-\beta C(a)-\gamma R(a)
\right]
]

其中：

* **迁移发现模式**提高 (\lambda)，优先选择最能区分竞争假设的实验；
* **闭环优化模式**降低 (\lambda)，优先改善多目标性能；
* (C(a)) 是实验成本；
* (R(a)) 是失败、越界和不可解释风险；
* 两种模式都使用同一套EIS质控、行为指标、证据门禁和记忆系统。

这比“迁移线用LLM、优化线用BO”更有研究价值，因为它把两者统一为：

> **在部分可观测、带噪声和高成本条件下，如何选择最有科学价值的下一实验。**

# 二、不要把单点电导率作为共同目标

建议把材料描述成一个统一的“传导行为向量”：

[
B=
[
\log\sigma(T_k),
AUC_{LT},
R_{LT},
E_a,
w_{\mathrm{Arr/VTF}},
T^*,
H_{\mathrm{thermal}},
D_{\mathrm{cycle}},
R_{\mathrm{batch}},
Q_{\mathrm{EIS}},
P_{\mathrm{feasible}},
C
]
]

核心组成包括：

| 层次     | 共同指标                              |
| ------ | --------------------------------- |
| EIS有效性 | 热平衡、线性、时间稳定性、KK/lin-KK一致性、频率窗充分性  |
| 传导行为   | 预定义温度锚点的电导率后验、低温曲线面积、低温保持率        |
| 温度模型   | Arrhenius、VTF、分段模型权重，变点概率与温度区间    |
| 稳定性    | 升降温滞后面积、循环漂移、恢复率                  |
| 复现性    | 批内重复性、独立批次复现概率                    |
| 可行性    | 可成膜、可装夹、可获得有效谱的概率                 |
| 科学可信度  | 主张—证据完整率、引用忠实率、无证据主张率             |
| 智能体校准  | Brier score、区间覆盖、选择性风险和拒答效用       |
| 优化效果   | simple regret、Pareto超体积、每个确认改进的成本 |

这样，迁移发现评价“预测签名是否出现”，闭环优化评价“行为向量是否改善”，不会出现两条线使用不同科学语言的问题。

# 三、迁移发现模式的推荐流程

### 1. 从“材料相似性”升级为“可迁移因果母题”

从酸–黏土文献中提取的重点不应只是“某材料与某材料相似”，而应是：

* 质子供体密度；
* 含水与低温水保持；
* 氢键网络连续性；
* 酸的固定和迁移；
* 黏土限域；
* 聚合物—黏土界面贯通；
* 聚合物链段运动；
* 冻结或相变抑制；
* 电极接触和几何伪影。

A-Lab类系统说明了文献知识、历史数据、机器学习、主动学习和实验反馈可以共同组成闭环，并且失败实验本身应当产生可行动的信息。([Nature][2])

### 2. 为每次跨体系推理建立“桥接假设”

例如：

> 酸–黏土体系中的低温传导现象能够迁移到淀粉–黏土膜。

不能作为一个整体假设。应拆成：

1. 生物聚合物能够保持足够的质子供体或酸；
2. 低温下仍存在连续的含水/氢键网络；
3. 聚合物不会切断黏土界面的传导连通性；
4. 制膜和调理过程不会造成不可逆脱水；
5. EIS中的变化不是接触或几何伪影。

每一个桥接假设都要有：

* 支持文献；
* 适用条件；
* 预测的EIS签名；
* 失败反例；
* 可推翻它的实验。

### 3. 把机理文字编译成实验前预测

例如某假设必须提前给出：

* 哪些温度锚点会发生变化；
* 是否预计存在变点；
* 升温和降温是否应重合；
* DRT或谱形应出现什么变化；
* 哪些材料应为正例；
* 哪些结构相似材料反而应该失败；
* 失败后否定的是哪一条桥接假设。

然后冻结预测，禁止实验结果出来后重新改写解释。

### 4. 候选组合不能只选“最看好的”

建议每轮组合同时包含：

* 预测正例；
* 结构相近但应失败的对抗性反例；
* 母体系对照；
* 空白或过程对照；
* 一个用于检验智能体是否在泛化式讲故事的候选。

这样藕粉、普通淀粉和壳聚糖不只是候选材料，而是具有明确假设功能的对照组。

# 四、闭环优化模式的推荐升级

## 代理模型应至少拆成三个

1. **性能模型**：预测完整传导行为向量；
2. **可行性模型**：预测可成膜、可装夹、能否获得有效谱；
3. **测量质量/失败模型**：预测漂移、未平衡、接触失效等风险。

不要把失败实验删除，也不要简单赋予一个极低电导率。失败本身是关于实验空间边界的重要数据。

## 推荐模型

在现有样本量下，优先考虑：

* 异方差高斯过程；
* 混合变量和混料约束；
* 多输出或多任务模型；
* 批次、日期、原料批号、热史作为上下文；
* 历史酸–黏土知识只作为可检验先验，不能作为事实标签；
* 分组或时间外验证，禁止普通随机拆分造成批次泄漏。

噪声会显著影响材料发现中的BO表现，代理模型需要同时表达信息不足和观测噪声，并在探索与利用之间分配实验。([皇家化学学会出版][3])

## 大模型的正确位置

大模型负责：

* 从文献生成有依据的先验；
* 建议变量、约束与候选解释；
* 检查与历史失败的冲突；
* 解释为什么推荐某实验；
* 识别需要人工审批的情况。

大模型不负责：

* 手算采集函数；
* 修改实测数据；
* 绕过硬约束；
* 直接选择一个“看起来最好”的配方；
* 直接向仪器发送未经验证的指令。

采集函数必须由可复算的数值代码产生，LLM只能在受控范围内审查或解释数值候选。

## 自适应重复

不要对所有实验做等量重复。应当在以下情况增加重复：

* 候选位于Pareto前沿；
* 两个候选排序接近；
* 偶然噪声大于知识不确定性；
* 结果与历史模型严重冲突；
* 即将进入独立确认阶段。

若主要是认知不确定性，则应探索新配方，而不是反复测同一点。

# 五、智能体应采用“受控编排器”，而不是堆很多Agent

推荐七层结构：

1. **证据与知识层**：文献、材料、样品、协议、反例和适用域；
2. **假设与主张层**：桥接假设、预测签名、竞争解释；
3. **策略路由层**：决定当前偏重假设判别还是性能优化；
4. **数值决策层**：层级贝叶斯、EIS模型比较、BO；
5. **实验执行层**：协议编译、前置检查、仪器调用和回滚；
6. **EIS质控与推断层**：有效性、模型比较、不确定度传播；
7. **科学记忆与治理层**：记忆、验证器、校准、审计和人工审批。

你们已经做好的记忆、自我检查和可靠性校准，应立即接入主流程，而不是继续作为旁路演示。

建议采用三种类型化记忆：

* **情景记忆**：每轮发生了什么、做了哪些选择、为什么失败；
* **语义记忆**：主张、证据、反例、桥接假设和适用条件；
* **程序记忆**：SOP、EIS分析流程、失败恢复策略和工具能力。

置信度必须在实验前记录，并用实验结果计算Brier score、log loss和可靠性曲线。不要使用模型实验后的自我评价代替校准。现有科学智能体基准也表明，端到端能力不能靠一次展示判断，需要对工作流中的每个任务做细粒度评测。([OpenReview][4])

# 六、必须实施的结论门禁

| 等级 | 可允许的主张                  |
| -- | ----------------------- |
| C0 | 数据无效，只报告失效原因            |
| C1 | 某条件下得到某EIS或电导率区间        |
| C2 | 某行为在独立批次下可复现            |
| C3 | 数据更支持某经验温度模型或传导区间       |
| C4 | 数据与某机制的预注册预测一致，但仍保留替代解释 |
| C5 | 通过结构证据与因果干预确认微观机制       |

当前系统默认只能到 **C4**。

每一条主张都必须输出：

* 主张等级和状态；
* 实验与文献证据ID；
* 配方、批次、温湿度和热史；
* 效应量与区间；
* 竞争模型权重；
* 替代解释；
* 可推翻该主张的结果；
* 适用域；
* 校准后的智能体置信度；
* 独立验证器结果。

状态只能是：

**Supported / Refuted / Inconclusive / Invalid**

尤其要允许系统输出“Inconclusive”。在你们的场景中，可靠地知道“现有数据无法区分两个解释”，本身就是高价值科学结果。

# 七、怎么证明这套系统真的有效

建议做四类严格比较：

| 验证       | 核心设计                                      |
| -------- | ----------------------------------------- |
| 历史数字回放   | 按时间和批次隐藏未来数据，让系统重做当时的实验选择                 |
| 前瞻迁移挑战   | 实验前冻结候选、正反例、预测签名和结论门槛                     |
| 固定预算优化比较 | 随机/LHS、传统DOE、BO-only、LLM-only、LLM+BO、完整系统 |
| 消融实验     | 分别去掉记忆、验证器、校准、负结果和自适应重复                   |

主要评价：

* 误支持科学主张的概率；
* 区间覆盖和置信校准；
* 正反例判别；
* 独立批次确认率；
* fixed-budget simple regret；
* Pareto超体积；
* 每个确认改进的实验成本；
* 人工干预率；
* 端到端确定性回放率。

自驱动实验室不应只报告“找到最好结果的速度”，还应报告自主度、可运行时间、参数空间、测量精度、吞吐量、采样成本和优化表现。([Nature][5])

# 八、最有价值的研究创新点

你们最强的论文主线不是“发现一个更高电导材料”，而可以是：

> **部分可观测、EIS-only、噪声和高实验成本条件下的证据校准型自主材料发现。**

可形成四项核心贡献：

1. **两种发现模式共享的传导行为向量和结论等级体系；**
2. **信息增益—性能改进—成本—风险统一采集策略；**
3. **把科学记忆、外部验证器、校准拒答真正接入湿实验闭环；**
4. **用正例、失败反例、预注册、消融和独立批次确认评估自主发现能力。**

真正需要突破的底层问题则是：

* 潜在材料状态不可观测条件下的贝叶斯信念建模；
* EIS逆问题和模型不可辨识性；
* 跨材料体系的因果迁移与桥接假设验证；
* 偶然噪声与认知不确定性的分离；
* 最优重复次数与下一新实验之间的价值信息决策；
* 科学Agent的概率校准和选择性拒答；
* 从原始谱到论文主张的机器可验证溯源。

数据和实验操作层建议采用机器可执行协议、不可变原始数据、W3C PROV式溯源以及RO-Crate式复现包；SiLA类功能接口可用于隔离仪器能力和上层Agent。([sila-standard.com][6])

> **每个模块单独看都运行正常，组合起来却稳定地产生错误科学结论。**

# 一、哪些东西可以直接用，哪些不能

我建议把现有技术分成三类。

## A类：可以直接采用其标准或数值内核

这些组件本身有明确输入输出，且可以通过单元测试验证：

* BoTorch、qNEHVI等优化器和采集函数数值实现；
* impedance.py、pyimpspec等EIS解析、基础拟合和Lin-KK实现；
* 数据库、对象存储、消息队列、工作流引擎；
* W3C PROV、RO-Crate等溯源和研究对象封装规范；
* SiLA 2等仪器通信规范；
* 容器化、哈希、版本控制、权限、审计等基础设施。

但“直接用”只意味着**不必重新发明底层算法或数据格式**，不意味着可以接受其默认科学解释。

例如，impedance.py提供预处理、数据验证、模型拟合和可视化；Lin-KK实现可以检查谱是否能被Kramers–Kronig相容模型重现。它解决的是数值实现和基础有效性检查，不会判断样品是否真正达到温度平衡、是否发生接触变化、湿度历史是否一致。([Impedance.py][1])

## B类：代码可以复用，但必须加领域适配层

包括：

* AutoEIS和自动等效电路搜索；
* DRT及其贝叶斯实现；
* 通用高斯过程和贝叶斯优化；
* 科学文献RAG；
* Agent规划和工具调用；
* 记忆、反思、多智能体辩论；
* LabOP等协议表示；
* 通用异常检测和漂移检测。

这些模块通常可以承担“候选生成器”“数值计算器”“语法转换器”，但不能直接担任科学裁决者。

## C类：不能直接复用，必须由你们重新定义

这些恰恰是你们最可能形成原创贡献的部分：

* 酸–黏土到生物聚合物–黏土的可迁移条件；
* 体系潜在状态和信念状态模型；
* EIS有效数据与材料负结果的区分；
* 从机理文字到可证伪EIS签名的编译；
* 结论C0–C5等级；
* 不同类型科学判断的任务特异性校准；
* 假设判别和性能优化的统一实验价值函数；
* 正例、反例、对抗性反例的实验设计；
* 端到端误支持结论率；
* 预注册、数字回放和系统消融。

# 二、现有技术最根本的不足：它们大多没有完成“科学语义闭环”

一个自主实验系统至少存在五个不同层面的“成功”：

| 层次   | 要回答的问题               |
| ---- | -------------------- |
| 执行成功 | 仪器是否完成了命令？           |
| 测量成功 | 得到的谱是否有效？            |
| 统计成功 | 参数与不确定度是否可信？         |
| 假设成功 | 数据是否真的区分了竞争解释？       |
| 科学成功 | 结论是否可复现、可证伪、未越过证据边界？ |

目前多数自动化实验室重点覆盖前两层，优秀系统开始覆盖第三层；真正系统性覆盖第四、第五层的仍然很少。

A-Lab是一个很典型、也很有价值的案例。它完成了机器人合成、文献配方、主动学习和XRD分析闭环，原始工作报告在57个目标中实现36个材料。但2026年的作者更正明确说明：此前有4个结果仅凭XRD不能无歧义确认，同时“新材料”的表述需要澄清为“对预测平台而言是新的”，而不一定是科学界从未发现的材料。([Nature][2])

这不说明A-Lab失败，恰恰说明：

> **自动执行成功、自动分析成功和科学主张成立，是三个不同的问题。**

原始工作中还存在人工Rietveld复核、人工重新研磨、更高温处理，以及一些超出主动学习算法适用范围的标准实验操作；只有约30%的353个具体合成配方直接获得了目标材料。([Nature][2])

而你们只有EIS，没有结构表征。EIS与微观结构之间的映射比“XRD是否出现某相”更加间接，所以你们的结论门禁必须比一般自动化优化平台更严格。

# 三、你们场景中最大的缺口：真实状态看不见

普通贝叶斯优化往往隐含一个简化模型：

[
y=f(x)+\epsilon
]

其中 (x) 是配方，(y) 是性能。

但你们真正面对的是：

[
z_{t+1}=g(z_t,x_t,p_t,e_t)
]

[
y_t=h(z_t,m_t)+\epsilon_t
]

这里：

* (z_t)：真实但不可直接观测的材料状态；
* (x_t)：配方；
* (p_t)：制备和调理过程；
* (e_t)：温湿度、时间、批次等环境；
* (m_t)：测量动作；
* (y_t)：观测到的EIS。

潜在状态至少包括：

* 含水状态；
* 酸的分布和固定程度；
* 聚合物链段状态；
* 黏土界面状态；
* 冻结或玻璃化相关状态；
* 样品厚度和局部不均匀性；
* 电极接触；
* 热历史；
* 老化或不可逆损伤。

这意味着同一个名义配方，在不同批次、不同调理时间、不同升降温历史下，并不是同一个输入点。

现成的BO、Agent和实验编排系统通常不会自动为你们建立这套潜在状态。它们容易把：

* 接触变差；
* 样品未平衡；
* 局部失水；
* 热循环不可逆变化；
* 原料批次漂移；

误学成“配方结构—性能关系”。

这不是多收几组数据就一定能解决的问题，而是**模型结构错误**。

# 四、P01–P32场景补丁中，现有技术具体缺在哪里

## 1. P01–P02：EIS数据契约和几何不确定度

### 已经有的

现有EIS库能读取多种文件格式，完成频率、实部、虚部解析，以及电路拟合。

### 不够的地方

多数软件把厚度和面积当成固定输入，然后计算：

[
\sigma=\frac{L}{RA}
]

但在你们的膜体系中：

* 厚度可能存在空间不均匀性；
* 低温收缩会影响有效几何；
* 电极实际接触面积不一定等于名义面积；
* 装夹压力会影响接触；
* 同一个厚度值可能来自单点测量，而不是分布；
* 几何误差和电阻误差可能相关。

直接输出单个电导率数字，会掩盖从原始阻抗、模型选择、几何测量到电导率的完整不确定度链。

### 你们必须补的

每个电导率结果必须绑定：

* 原始谱文件；
* 样品ID和批次；
* 厚度测量位置和方法；
* 面积定义；
* 电极与装夹方式；
* 温湿度和热历史；
* 电阻后验；
* 几何后验；
* 电导率后验；
* 软件、模型和参数版本。

也就是说，外部软件可以做计算，但不能定义你们的数据产品。

---

## 2. P03–P10：温度平衡、线性、稳定性、KK和失效谱

### 已经有的

Lin-KK、Kramers–Kronig检查、残差分析和部分异常检测已经相当成熟。impedance.py明确把线性、稳定性和因果性作为EIS有效性的重要前提。([joss.theoj.org][3])

### 不够的地方

通过Lin-KK并不等于：

* 样品已经达到温度平衡；
* 接触没有缓慢漂移；
* 湿度状态一致；
* 频率窗口足以捕捉目标过程；
* 没有低频时间漂移；
* 没有升降温不可逆效应；
* 所选电阻对应体相质子传导；
* 可以作出微观机制判断。

Lin-KK主要检查测得数据在当前频率窗口内是否能够被KK相容模型重现。它不是材料机制证明器，也不是完整的实验质控器。

### 你们必须补的

建议把谱的准入拆成至少六道独立门：

1. **仪器门**：open/short/reference/cable检查；
2. **状态门**：温度和环境达到预定义平衡；
3. **线性门**：扰动幅度扫描；
4. **时间不变性门**：重复谱、前后漂移；
5. **频率充分性门**：关键特征未被截断；
6. **数学一致性门**：KK、残差结构和拟合后验检查。

任何一道门失败，都不能简单编码成“低电导率”。

这是当前很多闭环优化系统最容易犯的错误：

> **无效实验结果被当成低性能材料，优化器因此学习了错误的材料空间边界。**

---

## 3. P11–P17：DRT、等效电路、贝叶斯拟合和不确定度传播

### 已经有的

AutoEIS可以自动提出统计上合理的等效电路，并进行贝叶斯模型选择。其公开验证覆盖薄膜析氧、电化学腐蚀和二氧化碳还原电解装置等体系。([NIST][4])

DRT的贝叶斯和层级贝叶斯方法也已有较成熟研究。

### 不够的地方

AutoEIS自己使用的是“**statistically plausible ECMs**”，即统计上合理的电路，而不是“物理机制已被确认的电路”。

原因包括：

* 多个电路可能拟合同一组谱；
* 一个电路参数可能对应多个物理过程；
* 参数之间可能不可辨识；
* 不同损失函数会得到不同拟合；
* 频率窗口不足时，参数可能看似收敛但实际不可识别；
* CPE、Warburg等元件容易被过度物理化；
* 单个温度下的最佳模型不一定能在全温区保持一致。

已有研究也指出EIS建模具有明显主观性，多种模型可能拟合同一数据；分数阶等效电路的结构可辨识性本身就是需要专门分析的问题。([arXiv][5])

DRT也不是“无模型真相”。其反演属于病态逆问题，需要正则化或先验；峰的位置、数量和宽度可能受正则化、噪声和频率窗口影响。([香港科技大学科研门户][6])

### 你们必须补的

外部工具只能作为：

* 电路候选生成器；
* DRT候选特征生成器；
* 参数后验计算器。

不能直接作为机制裁决器。

你们需要额外加入：

* 适用于膜质子导体的电路候选语法；
* 参数符号、范围和温度连续性先验；
* 多温度联合拟合；
* 多批次层级模型；
* 实用可辨识性检查；
* 先验敏感性分析；
* 后验预测检查；
* 留出频率预测；
* 模型平均；
* “电路元件—物理过程”映射的不确定度。

最终输出应该是：

> 模型A后验权重0.55，模型B为0.35，其他为0.10；两者都支持低频过程发生变化，但现有数据不能区分界面极化和接触变化。

而不是：

> 出现第二个半圆，因此证明发生了某种质子跃迁机制。

## 4. P18–P21：宽温行为、变点、滞后和批次层级

这部分几乎不可能从现成EIS软件中直接获得。

### 现有工具通常怎么做

常见流程是：

1. 每个温度独立拟合；
2. 得到每个温度的电阻；
3. 计算电导率；
4. 对 (\log\sigma) 与 (1/T) 做线性拟合；
5. 报告一个活化能。

### 对你们为什么不够

独立拟合忽略了：

* 相邻温度之间的参数连续性；
* 升温与降温路径差异；
* 样品状态的时间演化；
* 低温区变点；
* Arrhenius和VTF模型竞争；
* 热循环不可逆性；
* 批次和样品层级；
* 同一温度下偶然噪声和状态差异的分离。

一个看似明显的“低温机制转变”，可能实际来自：

* 某几个温度未平衡；
* 低频截断；
* 接触在降温时逐步恶化；
* 单个样品的不可逆变化；
* 不同温度独立拟合造成的参数跳跃。

### 你们必须补的

需要一个联合模型，而不是一系列独立拟合：

[
p\big(Z(\omega,T),\sigma(T),M,T^*,H
\mid D\big)
]

其中同时推断：

* 各温度下的电导率后验；
* Arrhenius、VTF、分段模型权重；
* 变点 (T^*) 的后验区间；
* 升降温滞后；
* 循环漂移；
* 样品内和批次间方差；
* 模型不确定度。

这很可能是你们项目中最有领域原创性的数学层之一。

---

## 5. P22–P28：迁移发现、桥接假设和证据门禁

### 已经有的

PaperQA2一类系统在科学文献检索、问答、综合和矛盾发现上已经取得很强的效果。Coscientist展示了文献搜索、代码执行、实验规划和实验自动化的组合；Co-Scientist则进一步使用多智能体生成、批评和迭代完善假设。([arXiv][7])

### 不够的地方

文献检索正确，并不等于跨体系迁移正确。

从酸–黏土迁移到生物聚合物–黏土，至少改变了：

* 质子供体和受体环境；
* 酸活度；
* 水结合状态；
* 聚合物链段运动；
* 黏土界面连续性；
* 酸的固定和流失；
* 冻结行为；
* 膜形貌和厚度；
* 电极接触方式；
* 制备与调理过程。

因果迁移理论的基本要求，就是显式说明源域和目标域哪些机制相同、哪些机制发生改变，以及在这些假设下源域证据是否可以运输到目标域。相似性本身不是运输许可证。([AAAI Publications][8])

### 现有Agent最容易犯的错误

它可能生成这样的推理：

1. 酸–黏土体系低温下保持较好传导；
2. 淀粉有丰富羟基；
3. 淀粉和黏土可形成氢键网络；
4. 因此淀粉–黏土膜也会有类似低温质子传导。

这段话语言上合理，但实际上跳过了多个独立桥接假设。

### 你们必须补的

每次迁移必须形成桥接假设表：

| 桥接假设       | 支持证据        | 反对证据    | 可观察预测      | 推翻条件        |
| ---------- | ----------- | ------- | ---------- | ----------- |
| 低温下保持足够可动水 | 文献、历史EIS    | 脱水或冻结证据 | 低温保持率、滞后特征 | 低温电导突降且不可恢复 |
| 酸被膜体系有效固定  | 酸–聚合物相互作用证据 | 酸流失风险   | 循环后恢复率     | 首轮后持续衰减     |
| 黏土界面形成贯通路径 | 类似复合体系      | 团聚和阻断风险 | 相对对照的谱形变化  | 加黏土反而持续恶化   |
| 观察不是接触伪影   | 接触对照        | 装夹敏感性   | 不同装夹重复一致   | 结果随压力显著变化   |

源域文献只能改变这些假设的**先验概率**，不能作为目标体系的实验观测。

---

## 6. P29–P31：贝叶斯优化、混料约束和成本价值

### 已经有的

BoTorch提供成熟、模块化的蒙特卡洛贝叶斯优化内核；qNEHVI可以处理带噪声的多目标优化和批量候选。([NeurIPS 会议论文集][9])

这些数值组件值得直接利用。

### 不够的地方

BO库不负责回答：

* 哪个观测是有效数据；
* 哪个失败是材料失败；
* 哪个失败是测量失败；
* 哪些变量是配方，哪些是过程，哪些是环境；
* 是否应当重复当前点；
* 是否应当探索新配方；
* 是否应优先验证机制；
* 某个提升是否跨批次成立；
* 某个候选是否值得承担实验风险。

已有跨五类实验材料系统的基准研究表明，代理模型选择会显著影响BO表现；各类高斯过程和随机森林并不存在脱离具体问题的统一最优选择。([Nature][10])

针对材料实验噪声的研究也发现，噪声会造成非单调收敛和不同优化运行之间的明显结果波动。([皇家化学学会出版][11])

### 你们至少要拆成三个代理模型

[
p(B\mid x,c)
]

性能行为模型：预测完整传导行为向量。

[
p(F=1\mid x,c)
]

实验可行性模型：能否成膜、装夹、完成测量。

[
p(Q=1\mid x,c)
]

测量质量模型：能否获得满足准入条件的有效谱。

其中 (c) 是：

* 原料批次；
* 制备日期；
* 操作者或设备状态；
* 调理历史；
* 热循环路径；
* 环境信息。

不得把三个模型合成一个“总分”。

### 大模型也不能替代采集函数

LLM可以：

* 提议新变量；
* 发现遗漏约束；
* 从文献构造先验；
* 对推荐进行科学解释；
* 检查与既有失败是否冲突。

但最终候选必须来自可复算的数值过程。否则无法区分：

* 候选是因为后验均值高；
* 因为不确定度大；
* 因为文献语言更丰富；
* 还是因为LLM偏好某种材料叙事。

---

## 7. P32：预注册、回放和消融

这部分几乎没有可直接搬用的“成品”。

原因是别人的基准往往评价：

* 找到最高性能点的速度；
* 自动运行时长；
* 任务完成率；
* 文献问答准确率；
* 代码执行成功率；
* 最终配方性能。

但你们真正需要评价的是：

[
P(\text{错误地支持一个科学主张})
]

以及：

* 正例命中率；
* 反例拒绝率；
* “证据不足”识别率；
* 独立批次确认率；
* 置信校准；
* 区间覆盖；
* 单位确认结论的实验成本；
* 去掉某个Agent能力后系统退化多少；
* 是否能够从原始数据确定性回放到最终主张。

因此，P32不是普通软件测试，而是你们自主发现系统的**科学临床试验**。

# 五、现有科学Agent为什么不够好

## 1. 它们擅长生成和执行，不擅长限制自己能说什么

Coscientist已经展示了搜索、规划、代码和实验自动化组合，并在包括钯催化偶联优化在内的任务上完成半自主设计与执行。([Nature][12])

但“会完成实验”不等于“知道结论只能到C2还是C4”。

通用Agent通常输出一段完整叙事，而不是：

* 哪些是事实；
* 哪些是模型结果；
* 哪些是类比；
* 哪些是推断；
* 哪些是未验证假设；
* 哪些替代解释仍然存在；
* 什么结果会推翻当前判断。

你们需要的不是更会说的Agent，而是**有主张权限控制的Agent**。

## 2. 多Agent辩论不是独立证据

多个Agent如果：

* 使用相同基础模型；
* 阅读相同文献；
* 使用相似提示；
* 共享相同错误先验；

那么它们的错误高度相关。

三个Agent都同意某个机制，并不等于三个实验室独立复现。

多Agent适合作为：

* 候选解释生成；
* 反驳搜索；
* 条件遗漏检查；
* 引用核查；
* 形式化规则检查。

不应把“投票比例”直接解释成科学置信度。

## 3. 假设生成的奖励函数通常不对

Co-Scientist使用多智能体持续生成、批评和完善假设，并通过竞赛式过程改善假设质量；其公开验证集中在三个生物医学应用。([Nature][13])

但在你们场景中，“高质量假设”不能只意味着：

* 新颖；
* 逻辑完整；
* 文献支持多；
* 专家看起来合理。

更重要的是：

[
\text{假设价值}
\approx
\frac{\text{可区分竞争解释的信息量}}
{\text{实验成本与失败风险}}
]

因此每个假设必须被编译成：

* 预期效应方向；
* 预期温度区间；
* 预期谱形或行为变化；
* 允许误差；
* 正对照；
* 负对照；
* 对抗性反例；
* 推翻条件；
* 与竞争假设的区分点。

---

# 六、记忆、自我检查和校准为什么不能直接接入

## 1. 通用记忆会把错误叙事长期固化

Reflexion等框架证明了Agent可以利用任务反馈进行文字反思，并把反思写入情景记忆，以改善后续任务表现。([NeurIPS 论文集][14])

但科学记忆与普通Agent记忆不同。

普通记忆可能写：

> 淀粉–黏土体系在低温下表现优异，可能由于氢键网络增强。

科学记忆必须拆成：

* 观测事实；
* 数据有效性；
* 统计效应；
* 当前解释；
* 替代解释；
* 主张等级；
* 适用条件；
* 证据ID；
* 反例；
* 版本；
* 是否已被后续证据推翻。

否则一条早期、错误但语言流畅的总结，会持续影响后续检索、候选排序和解释。

## 2. 自我检查不能由同一模型空想完成

研究显示，在没有外部反馈时，LLM的内在自我修正可能不但不改善结果，反而降低推理性能。([arXiv][15])

因此你们的自我检查必须调用外部依据：

* 数值代码；
* 数据库约束；
* 单位检查器；
* 统计验证器；
* 引用蕴含模型；
* 原始谱；
* 实验状态机；
* 独立提示和独立模型；
* 人工审批。

“再想一遍”不是验证。

## 3. 通用置信度不能直接解释为科学可靠性

研究发现，语言模型能够在部分任务上表达有用的置信度，但其对新任务的 (P(\text{I know})) 校准会明显变差。([arXiv][16])

所以不能让Agent输出一个统一的“可信度85%”。

你们至少需要分别校准：

* 文献事实抽取正确率；
* 引用是否支持主张；
* 桥接假设成立概率；
* 候选成为正例的概率；
* EIS谱有效概率；
* 独立批次复现概率；
* 某经验模型优于竞争模型的概率；
* 某机制解释与观测一致的概率。

这些概率对应不同事件、不同基准率，不能混为一个总置信度。

而且置信度必须在实验结果揭示前冻结，随后用Brier score、log loss、可靠性曲线和选择性风险评价。实验后再让Agent评价自己“当时有多确定”，没有校准意义。

# 七、标准和可复现工具为什么也不够

## SiLA 2解决的是通信，不是科学状态

SiLA 2定义了服务器功能、命令、参数和可读取属性，适合仪器接入和厂商中立接口。([SiLA快速集成][17])

但下面两个命令并不等价：

```text
set_temperature(-20 °C)
run_eis()
```

和：

```text
将样品置于-20 °C；
等待样品内部状态达到稳定；
验证连续温度和阻抗探针漂移均低于阈值；
确认接触未改变；
执行小信号线性检查；
运行EIS；
重复局部频率点验证时间不变性。
```

SiLA可以承载这些命令，却不会替你们定义哪些前后条件构成科学有效实验。

## W3C PROV解决“发生了什么”，不解决“做得对不对”

W3C PROV可以表达实体、活动、Agent及其派生关系，并用于支持对数据质量、可靠性和可信性的评估。([W3C][18])

但这是记录框架，不是领域裁决规则。

一个错误实验也可以拥有完美的PROV记录。

## RO-Crate解决封装，不保证别人能复现

RO-Crate可以把数据、方法、输出、人员、仪器等上下文组织成机器可读研究对象，也能够记录生成数据所使用的设备。([researchobject.org][19])

但如果你们没有记录：

* 电极接触压力；
* 样品局部厚度；
* 调理时间；
* 实际湿度轨迹；
* 温度平衡判据；
* 升降温方向；
* 失败后的人工干预；
* 仪器固件；
* 拟合先验；
* 模型选择规则；

那么RO-Crate只能把不完整信息封装得很好。

因此标准可以直接采用，但你们必须定义自己的：

> **质子导体宽温EIS最小可复现信息规范。**

# 八、最容易出现的系统级“组合错误”

下面这个流程中，每个模块都可能显示“成功”：

1. 温控设备报告已到达 (-20^\circ\text{C})；
2. Agent立即启动EIS；
3. 谱通过基础Lin-KK；
4. AutoEIS选出一个双时间常数电路；
5. 低频电阻显著增加；
6. BO把这个配方标记为低性能；
7. 文献Agent检索到低温冻结相关论文；
8. 大模型解释为水网络冻结导致传导通道破坏；
9. 多Agent投票同意；
10. 结论进入科学记忆。

但真实原因可能只是：

* 样品尚未平衡；
* 电极在降温时发生接触变化；
* 低频扫描期间样品持续漂移。

这时：

* 仪器没错；
* Lin-KK代码没错；
* AutoEIS没错；
* BO没错；
* RAG没错；
* LLM语言也可能完全合理；

**错的是模块之间没有科学契约。**

因此你们必须设置跨模块不变量：

* 未通过状态门的谱不得进入材料性能模型；
* 无效实验不得编码成低性能；
* 等效电路元件不得自动升级为物理机制；
* 文献类比不得作为目标体系的观测值；
* 实验后不得修改实验前预测；
* Agent投票不得直接转化为科学置信度；
* C4结论不得在文本生成时被改写成C5；
* 所有最终主张必须能够追溯到原始谱和具体批次。

---

# 九、对外部技术的准入测试

任何外部组件接入主流程前，都应提交一张“组件科学合同”。

| 准入问题               | 不满足时的处理        |
| ------------------ | -------------- |
| 它究竟完成什么任务，不完成什么？   | 禁止接入           |
| 它依赖哪些统计、物理和数据假设？   | 假设不透明则只允许旁路运行  |
| 训练或验证数据与本体系差异是什么？  | 标记为域外组件        |
| 输出是否包含可校准的不确定度？    | 不得参与自动结论       |
| 失败如何表示？            | 不允许用缺失值或极低性能代替 |
| 遇到域外输入是否会拒绝？       | 无拒绝能力则加外部OOD门  |
| 是否可固定版本、参数和随机种子？   | 不得进入正式回放       |
| 在你们历史数据上是否通过批次外测试？ | 只能影子运行         |
| 加入该模块是否降低端到端误结论率？  | 没有改善就不进入主流程    |
| 去掉该模块，系统性能是否真实下降？  | 消融无贡献则删除       |
| 人工干预是否完整记录？        | 未记录结果不得用于自主度声明 |
| 输出能否追溯到原始数据和证据？    | 不得生成正式科学主张     |

这里最重要的一条不是“模块自己的准确率”，而是：

> **接入它之后，系统错误支持科学主张的概率是上升还是下降。**

一个文献Agent即使问答准确率很高，如果它让系统更容易把类比写成因果结论，就可能对整体系统有负价值。

# 十、建议的实际复用方案

## 直接复用，但降级其权限

| 外部技术                     | 在你们系统中的正确角色    |
| ------------------------ | -------------- |
| impedance.py / pyimpspec | 谱解析、基础验证和拟合数值库 |
| AutoEIS                  | 等效电路候选生成器      |
| DRT工具                    | 时间尺度特征候选生成器    |
| BoTorch / qNEHVI         | 代理模型和采集函数计算引擎  |
| PaperQA类工具               | 文献候选证据检索器      |
| LLM Agent                | 假设与实验方案编译器     |
| 多Agent                   | 反驳、遗漏和冲突检查器    |
| Reflexion类记忆             | 记忆机制参考实现       |
| SiLA 2                   | 仪器能力接口         |
| LabOP                    | 协议表示基础         |
| W3C PROV                 | 溯源关系基础         |
| RO-Crate                 | 复现包封装基础        |

## 必须由你们掌握的核心层

1. **样品潜在状态模型；**
2. **宽温EIS数据准入规则；**
3. **EIS多模型与不可辨识性处理；**
4. **酸–黏土到生物聚合物–黏土的桥接假设；**
5. **正例、负例和对抗性反例设计；**
6. **假设到可观察签名的编译；**
7. **迁移发现和闭环优化的统一价值函数；**
8. **自适应重复策略；**
9. **主张—证据—反例图；**
10. **C0–C5结论门禁；**
11. **任务特异性置信校准；**
12. **前瞻、预注册和消融基准。**

# 最终结论

你们不应该重新开发所有底层技术，也不应该把现有端到端系统直接搬进来。

更合理的策略是：

> **复用别人的计算器、接口、解析器和执行器；重新建立你们自己的观测模型、证据规则、决策规则和结论权限。**

你们真正可能领先的地方，不是“再造一个更大的科学Agent”，而是建立一套：

> **在隐状态不可见、EIS逆问题不可唯一识别、实验昂贵且样本有限时，仍能约束自主系统不把执行成功误写成科学发现的认知操作系统。**

# 方案一：可知性驱动的隐状态科学控制

## Epistemic Dual-Control Laboratory

## 1. 它解决的根问题

你们现在表面上的问题是：

> 没有结构表征，只有EIS，能不能推断机制？

更底层的问题其实是：

> 在给定传感器和可执行实验集合下，哪些潜在状态原则上可辨识，哪些只能部分辨识，哪些根本不可辨识？

现有闭环优化通常假设：

[
y=f(x)+\epsilon
]

其中 (x) 是配方，(y) 是电导率或某个性能。

但真实湿实验更接近：

[
z_{t+1}=F(z_t,x_t,u_t,w_t)
]

[
Y_t=G(z_t,m_t)+\epsilon_t
]

其中：

* (z_t)：不可直接观测的真实状态；
* (x_t)：材料或制备动作；
* (u_t)：调理、温度路径、等待时间等状态控制动作；
* (m_t)：频率范围、激励幅值、重复、升降温方向等测量动作；
* (Y_t)：最终得到的阻抗谱；
* (w_t)：环境、批次、接触变化和随机扰动。

你们的智能体目前主要在选择 (x_t)，但真正应该联合选择的是：

[
a_t=(x_t,u_t,m_t)
]

即同时设计：

* 做什么样品；
* 怎样改变它的状态；
* 怎样测量才能最大程度看清它。

2025年的在线贝叶斯实验设计研究已经开始处理“部分可观测动态系统”，使用状态空间模型和嵌套粒子滤波，对潜在状态积分后计算期望信息增益；但它仍是通用数学框架，并未处理EIS逆问题、湿实验热历史、物理约束和科学主张边界。([arXiv][3])

---

## 2. 核心原创点：把“可知性”而不是“性能”作为第一优化目标

定义关于潜在状态、模型参数和竞争假设的信念状态：

[
b_t(z,\theta,H)
===============

p(z_t,\theta,H\mid\mathcal D_t)
]

每次实验不再单纯最大化性能改善，而是最大化：

[
a_t^*
=====

\arg\max_a
\left[
I(z,\theta,H;Y_{t+1}\mid a,\mathcal D_t)
-\beta C(a)
-\gamma R(a)
-\kappa A(a)
\right]
]

其中：

* (I)：实验带来的信息增益；
* (C(a))：实验成本；
* (R(a))：失效和越界风险；
* (A(a))：实验后仍然残留的模型混叠或不可辨识性。

闭环优化中的性能改善可以作为次级项加入，但不能覆盖可知性：

[
J(a)=
\lambda_{\mathrm{know}}J_{\mathrm{know}}
+
\lambda_{\mathrm{use}}J_{\mathrm{use}}
-\beta C-\gamma R
]

在迁移发现模式中提高 (\lambda_{\mathrm{know}})；在性能优化阶段才逐步提高 (\lambda_{\mathrm{use}})。

### 这项创新的关键不是“用了POMDP”

而是提出一个新的自驱动科学原则：

> **当潜在状态不可见时，自主实验首先要优化观测系统本身的可辨识性，然后才有资格优化材料空间。**

---

## 3. 数学创新：科学可观测性和机制等价类

对于某组实验动作 (A)，定义广义Fisher信息矩阵：

[
\mathcal I_A
============

\sum_{a\in A}
J_a^\top
\Sigma_a^{-1}
J_a
]

其中：

[
J_a=
\frac{\partial \mathbb E[Y\mid z,\theta,a]}
{\partial(z,\theta)}
]

定义最差方向的可观测性：

[
\mathcal O(A)=\lambda_{\min}(\mathcal I_A)
]

如果某些方向对应的特征值接近零，就说明：

* 无论再多测几次类似EIS；
* 无论等效电路拟合多漂亮；
* 这些潜在状态仍不可区分。

更重要的是，可以定义**机制的实验等价关系**：

[
H_i\sim_{\mathcal A}H_j
\quad\Longleftrightarrow\quad
\sup_{a\in\mathcal A}
D_{\mathrm{JS}}
\left(
p(Y\mid H_i,a),
p(Y\mid H_j,a)
\right)
<\delta
]

含义是：

> 在你们当前可以执行的全部实验中，两个机制产生的预测分布都足够接近。

此时智能体不得选择 (H_i) 或 (H_j) 中的一个作为“真实机制”，只能报告：

> 当前实验能力只能识别到等价类 ([H_i,H_j])。

这会产生一个非常重要的新型科学结果：

## **不可辨识性证书**

证书不是说“数据少，所以不知道”，而是说：

* 在当前传感器；
* 当前噪声水平；
* 当前实验动作集合；
* 当前成本约束下；

哪些机制原则上不能区分，以及最少需要增加哪类干预或传感器才能打破等价。

这比给出一个貌似确定的机制结论更有基础研究价值。

---

## 4. 物理创新：把测量协议变成主动传感器

虽然只有EIS，但并不意味着只有一个观测通道。

你们可通过主动改变实验协议，形成一组“虚拟传感器”：

[
\mathcal M=
{
\text{频率窗口},
\text{扰动幅值},
\text{温度方向},
\text{等待时间},
\text{重复间隔},
\text{局部回温},
\text{热循环顺序},
\text{装夹条件}
}
]

不同机制、隐状态和伪影对这些扰动的响应并不相同。

因此可把传统的宽温EIS从：

> 在一系列温度点被动测谱

改成：

> 对潜在状态进行主动系统辨识。

例如，真正的材料状态变化和接触变化可能在以下维度上表现不同：

* 对等待时间的响应；
* 对升降温方向的响应；
* 对激励幅值的响应；
* 对局部频率重测的响应；
* 对短时回温的恢复行为；
* 对重复装夹的敏感程度。

核心不是预设哪个现象属于哪个机制，而是让竞争模型提前给出这些响应的概率预测，再选择最能区分它们的协议。

物理硬约束包括：

* 因果性；
* 线性响应条件；
* 稳定性；
* 被动性或正实性；
* 温度演化连续性；
* 状态变量的合理时间尺度；
* 热历史和迟滞；
* 几何量及接触参数的不确定度传播。

---

## 5. 计算机创新：信念状态操作系统

智能体不能直接看到一个“电导率表格”后开始推理。

它只能读取一个结构化信念对象：

```text
BeliefState
├── latent_state_posterior
│   ├── hydration_like_state
│   ├── contact_state
│   ├── thermal_history_state
│   └── irreversible_change_state
├── competing_model_weights
├── structural_ambiguity
├── measurement_validity_probability
├── batch_effect_posterior
├── observability_deficit
└── admissible_claim_ceiling
```

其中模型必须区分三种不确定性：

1. **观测噪声**：重复实验可能减小；
2. **知识不确定性**：探索新实验可能减小；
3. **结构不可辨识性**：仅增加同类数据通常无法减小。

LLM只能对这个信念状态进行解释、提出模型或提出实验动作，不能直接覆盖数值后验。

---

## 6. 最值得形成的理论成果

这个方向可以产生四个真正的基础贡献：

### A. EIS-only条件下的可辨识边界

证明什么类型的潜在动态状态在什么实验协议下局部或全局可辨识。

### B. 最小观测成本下界

给出区分两个机制等价类至少需要多少次、什么类型的实验。

### C. 双控策略

实验既改变系统状态，又学习系统状态；研究短期信息增益和长期科学决策之间的权衡。

### D. 可知性拒答

系统不仅输出结论，还输出：

[
\text{Knowable / Partially Knowable / Unidentifiable}
]

## 7. 怎样证明它不是普通BO

故意向盲测系统中注入：

* 接触状态变化；
* 不充分热平衡；
* 热历史差异；
* 批次隐变量；
* 一个无法通过当前EIS协议区分的竞争机制。

比较：

* 普通BO；
* BO + LLM；
* 层级GP；
* 可知性驱动双控系统。

评价指标不是最高材料性能，而是：

* 潜在状态识别率；
* 对不可辨识问题的正确拒答率；
* 后验覆盖率；
* 错误机制支持率；
* 每消除一个竞争解释的实验成本；
* 隐变量存在时的决策退化程度。

# 方案二：对抗式可证伪科学市场

## Scientific Falsification Exchange

## 1. 它解决的根问题

现有多智能体系统的默认逻辑通常是：

* 一个Agent提出；
* 一个Agent批评；
* 一个Agent总结；
* 多数Agent投票；
* 最终形成共识。

但多个Agent可能共享：

* 同一个基础模型；
* 相同训练语料；
* 相似检索结果；
* 相同的语言偏好；
* 相同的错误机制先验。

所以：

[
\text{Agent共识}\neq\text{独立证据}
]

真正要解决的是：

> 如何让智能体因为过度自信、避开反例或制造漂亮叙事而付出代价，同时因为找到高价值反例而获得奖励？

这不是提示词问题，而是**机制设计问题**。

---

## 2. 核心原创点：把科学闭环设计成有激励约束的博弈

设置四类角色。

| 角色    | 权限          | 收益来源        |
| ----- | ----------- | ----------- |
| 提议者   | 提出假设和预测分布   | 预测准确、适用域正确  |
| 证伪者   | 搜索替代解释和反例实验 | 以低成本推翻错误主张  |
| 实验审计者 | 判断实验是否有效    | 识别状态和测量伪影   |
| 裁决器   | 执行预注册规则     | 不生成解释，只执行规则 |

提议者不能只说：

> 我认为假设成立，置信度80%。

它必须提交一个**带押注的预测合同**：

[
\mathcal C_H=
{
H,,
p(Y\mid H,a),,
\mathcal D_H,,
\mathcal F_H,,
s_H
}
]

其中：

* (p(Y\mid H,a))：在不同实验下的预测分布；
* (\mathcal D_H)：适用域；
* (\mathcal F_H)：明确推翻条件；
* (s_H)：投入的科学置信资本。

结果出现后，按照严格适当评分规则更新Agent的信誉和决策权。适当评分规则的基本性质是：如果Agent希望最大化长期期望得分，诚实报告自己的概率判断是最优策略；相关工作也已把适当评分和委托—代理的信息获取博弈联系起来。([Taylor & Francis Online][4])

---

## 3. 证伪者不写批评文章，而是选择最便宜的杀伤实验

定义候选主张 (H_i) 和竞争解释集合：

[
\mathcal Q_i=
{
H_j,
C_{\mathrm{contact}},
C_{\mathrm{equilibrium}},
C_{\mathrm{geometry}},
C_{\mathrm{history}},
C_{\mathrm{model}}
}
]

证伪者选择实验：

[
a^*=
\arg\max_a
\frac{
\min_{q\in\mathcal Q_i}
\mathbb E
\left[
\log
\frac{p_i(Y\mid a)}
{p_q(Y\mid a)}
\right]
}{
C(a)+\rho R(a)
}
]

这里最大化的不是材料性能，而是：

> 单位实验成本对最难区分替代解释的最小判别能力。

可以把它称为：

[
\text{Falsification Value per Cost}
]

或者“单位成本证伪价值”。

这会改变实验文化：

* 不再优先做最可能成功的实验；
* 优先做最可能暴露当前解释脆弱性的实验；
* 正例和反例拥有相同科学地位；
* 能够快速杀死错误假设的实验是高价值实验。

---

## 4. 博弈论创新：科学资本和动态信誉

每个Agent拥有有限的科学资本 (W_k)。

每次预测后：

[
W_{k,t+1}
=========

W_{k,t}
\exp
\left(
-\eta S(p_{k,t},y_t)
\right)
]

其中 (S) 是适当评分损失。

结果是：

* 经常过度自信的Agent快速失去决策权；
* 只说模糊正确话的Agent不会获得高收益；
* 能给出尖锐且校准良好预测的Agent获得更多预算；
* 能提出有效反例的证伪Agent获得更高实验提案权；
* 恰当拒答不会被当作失败；
* 无条件“唱反调”同样会受到惩罚。

还可以设定一个Stackelberg博弈：

1. 主系统发布奖励规则；
2. 提议Agent选择投入多少推理和检索资源；
3. 证伪Agent选择投入多少反例搜索资源；
4. 实验结果决定双方收益。

这样研究的不只是“Agent会不会推理”，而是：

> 什么激励规则能让有限理性的科学Agent主动寻找真实信息，而不是制造共识？

---

## 5. 统计创新：允许连续观察，但不允许偷看数据后改规则

闭环实验必然具有：

* 边做边看；
* 看到结果后决定是否继续；
* 动态改变实验；
* 提前停止；
* 同时维护多个假设。

普通固定样本统计方法容易被这种自适应过程破坏。

应使用：

* e-value；
* e-process；
* 时间一致置信序列；
* 在线多重检验；
* 预注册的证据阈值。

e-process和置信序列可以在连续监控、可选停止条件下维持时间一致的统计保证。([Project Euclid][5])

例如对某个主张维护证据过程：

[
E_t=
\prod_{s=1}^{t}
\frac{
p_1(Y_s\mid a_s,\mathcal F_{s-1})
}{
p_0(Y_s\mid a_s,\mathcal F_{s-1})
}
]

只有当：

[
E_t\geq\frac{1}{\alpha}
]

且通过其他物理和复现门禁时，才允许主张升级。

这意味着Agent可以自适应地决定下一实验，却不能因为“刚好看到好结果”就停止并宣布发现。

---

## 6. 物理层的证伪者必须攻击什么

证伪Agent不应该只找文献反例，而应维护物理攻击库：

### 状态攻击

* 是否未达到平衡；
* 是否存在慢状态漂移；
* 是否有不可逆热历史；
* 是否为湿度或含水历史差异。

### 测量攻击

* 扰动是否仍在线性区；
* 频率窗口是否截断关键过程；
* 是否为装夹或接触变化；
* 几何不确定度是否足以解释效应。

### 模型攻击

* 是否存在近似等价电路；
* DRT峰是否对正则化敏感；
* 变点是否由独立温度拟合产生；
* Arrhenius/VTF/分段模型是否无法区分。

### 迁移攻击

* 源域知识到底支持哪个桥接假设；
* 目标体系改变了哪些结构方程；
* 是否仅因为语言相似而进行机制迁移。

---

## 7. 为什么这比多Agent辩论创新得多

2026年的DASES已经提出让候选在合法的对抗环境下持续接受自适应证伪，并强调固定测试集容易被自动系统“优化考试”。([arXiv][6])

但最接近的这类工作仍主要验证于机器学习损失函数发现。你们可以进一步提出：

> **面向真实湿实验、部分可观测状态、昂贵实验和自适应统计的激励相容证伪博弈。**

关键扩展包括：

* 真实物理环境作为最终裁判；
* 实验有效性审计者；
* 适当评分与科学资本；
* 随时有效的序贯统计；
* 反例实验的成本优化；
* 机制主张和测量伪影的对抗分离。

---

## 8. 怎样验证这个方向

向系统中预埋四类任务：

1. 正确但难验证的假设；
2. 错误但文献支持丰富的假设；
3. 结果正确但机制解释错误的假设；
4. 由接触、平衡或历史造成的伪发现。

比较：

* 单Agent；
* 普通多Agent辩论；
* 多Agent + 验证器；
* 对抗式科学市场。

评价：

* 错误主张支持率；
* 单位成本证伪率；
* 过度自信惩罚后的校准；
* 对“证据不足”的识别率；
* 证伪Agent是否学会寻找真正有效的实验；
* 连续实验中的假阳性控制；
* 最终幸存主张对独立批次的迁移程度。

这个方向的核心论文命题可以概括为：

> **从多智能体共识，转向激励相容的认知竞争。**

# 方案三：证明携带的科学编译器

## Proof-Carrying Science Compiler

## 1. 它解决的根问题

当前Agent的工作方式通常是：

[
\text{自然语言假设}
\rightarrow
\text{自然语言实验计划}
\rightarrow
\text{实验}
\rightarrow
\text{自然语言解释}
]

问题在于，自然语言中的以下概念没有严格边界：

* 观察；
* 派生量；
* 模型依赖推断；
* 类比；
* 假设；
* 机制主张；
* 因果主张；
* 证据不足。

所以Agent很容易发生非法跳跃：

[
\text{一个谱形变化}
\Rightarrow
\text{某电路元件变化}
\Rightarrow
\text{某物理过程变化}
\Rightarrow
\text{证明某微观机制}
]

你们需要的不是另一个实验工作流语言，而是：

> **把自然语言科学假设编译成可执行、可证伪、可验证的形式对象。**

---

## 2. 核心原创点：科学结论必须是一个“带证明对象”

编译链如下：

```text
自然语言假设
    ↓
科学中间表示 Scientific IR
    ↓
潜在变量与可观测量
    ↓
竞争模型集合
    ↓
可执行干预空间
    ↓
预测分布与推翻条件
    ↓
最小判别实验集合
    ↓
机器可执行协议
    ↓
预注册分析程序
    ↓
证据对象
    ↓
带类型的科学主张
```

最终输出的不是一段报告，而是：

```text
ClaimCertificate
├── claim_type
├── claim_level
├── domain_of_validity
├── assumptions
├── competing_models
├── preregistered_predictions
├── raw_data_hashes
├── protocol_hash
├── analysis_code_hash
├── quality_gate_results
├── statistical_evidence
├── falsification_trace
├── independent_replication
├── unresolved_alternatives
└── invalidation_conditions
```

---

## 3. 类型系统：禁止从原始数据直接跳到机制结论

可以定义如下类型：

```text
RawSpectrum
ValidSpectrum
DerivedConductivity<Model>
BehaviorEvidence
ReplicatedEvidence
ModelDiscrimination<Hi, Hj>
MechanismConsistentEvidence
Claim<C0...C5, Domain>
```

合法构造路径：

[
\texttt{RawSpectrum}
\xrightarrow{\mathrm{QC}}
\texttt{ValidSpectrum}
]

[
\texttt{ValidSpectrum}
\xrightarrow{\mathrm{model\ averaging}}
\texttt{BehaviorEvidence}
]

[
\texttt{BehaviorEvidence}
\xrightarrow{\mathrm{independent\ batch}}
\texttt{ReplicatedEvidence}
]

[
\texttt{ReplicatedEvidence}
+
\texttt{ModelDiscrimination}
\xrightarrow{}
\texttt{Claim<C4>}
]

不存在下面这条构造函数：

[
\texttt{RawSpectrum}
\not\rightarrow
\texttt{MechanismClaim}
]

这不是写作模板，而是计算机类型系统。

如果证据条件不满足，程序无法构造C4对象，文本生成器也就无权输出C4语句。

---

## 4. 数学创新：自动寻找最小判别实验基

设有竞争模型：

[
\mathcal H={H_1,\ldots,H_K}
]

以及允许执行的实验动作：

[
\mathcal A={a_1,\ldots,a_M}
]

每个模型在每个实验下给出预测分布：

[
p(Y\mid H_i,a_j)
]

寻找最小成本实验集合：

[
S^*
===

\arg\min_{S\subseteq\mathcal A}
\sum_{a\in S}c(a)
]

满足：

[
\forall i\neq j,\quad
\max_{a\in S}
D_{\mathrm{JS}}
\left(
p(Y\mid H_i,a),
p(Y\mid H_j,a)
\right)
\geq\delta
]

并要求：

[
P(\text{实验有效}\mid a)\geq 1-\alpha
]

它本质上是：

* 加权集合覆盖；
* hitting set；
* 组合优化；
* 鲁棒模型判别；
* 最小干预设计。

2025年的JMLR工作已经证明，最小成本因果效应识别实验设计可与minimum hitting set建立联系，并且一般问题是NP完全的，可采用精确或对数近似算法。([机器学习研究杂志][7])

你们可以把这一思想扩展到：

> **带潜在状态、EIS观测模型、实验失效概率和物理约束的最小机制判别实验编译。**

这比“让LLM给出下一个实验”深得多。

---

## 5. 编译器最重要的输出可能是“编译失败”

假设Agent提出：

> 低温下传导保持来自某种氢键网络机制。

编译器要问：

1. 有哪些竞争解释？
2. 各解释对当前可测量量给出什么不同预测？
3. 是否存在可执行实验能可靠区分它们？
4. 当前噪声和样本数下，差异是否可检测？
5. 是否存在混杂状态可产生相同结果？

如果找不到判别实验，则输出：

```text
Compilation failed:
Claim is not identifiable under current sensing and intervention set.

Unresolved equivalence class:
{H1, H2, H3}

Required new capability:
one of {intervention class A, sensor class B, stronger prior C}
```

这是非常有价值的结果：

> 智能体不仅告诉你“我不知道”，还给出为什么不知道，以及增加哪种实验能力后才可能知道。

---

## 6. 物理编译器：从机制文字到响应分布

每个机制假设不能只是一段语言，而必须实现一个模型接口：

```text
MechanismModel:
    latent_states()
    admissible_parameters()
    state_dynamics()
    impedance_forward_operator()
    predicted_invariants()
    predicted_failure_modes()
    domain_of_validity()
```

不要求一开始就有完整微观模型，可以由以下层次组成：

* 物理约束下的现象模型；
* 状态空间模型；
* 多模型集合；
* 带未知函数的半参数模型；
* 经验模型与机制模型的组合。

重要的是，每个模型必须输出：

[
p\big(
Z(\omega,T,\text{path})
\mid
H,a
\big)
]

而不是只输出一句“预计电导率会上升”。

编译时执行物理静态检查：

* 是否满足因果性；
* 是否满足线性响应适用条件；
* 是否满足被动性；
* 参数是否可能不可辨识；
* 是否存在等价模型；
* 是否违反温度连续性；
* 是否忽略热历史；
* 是否把等效电路元件直接等同为物理机制。

---

## 7. 计算机科学创新：LLM只做前端，形式化系统掌握执行权

合理分工是：

| 层      | 技术            |
| ------ | ------------- |
| 自然语言前端 | LLM           |
| 科学中间表示 | DSL、知识图和类型系统  |
| 一致性验证  | SMT/SAT、规则引擎  |
| 协议验证   | 时序逻辑、状态机、模型检查 |
| 数值推断   | 确定性统计代码、概率程序  |
| 实验选择   | 组合优化、贝叶斯实验设计  |
| 结论构造   | 证明对象生成器       |
| 文本输出   | 从证明对象受控生成     |

已有工作已经证明，LLM生成的形式模型可以交给模型检查器验证，并利用反例进入修复循环。([arXiv][8]) 另有2026年的实验Agent工作开始把概率语言模型和确定性实验执行层分离。([arXiv][9])

你们可以把这两个思想推进到科学主张层：

> 不只验证命令有没有执行错误，还验证“这个证据是否有资格构造这个科学结论”。

---

## 8. 与现有实验编排系统的本质区别

IvoryOS等系统重点解决跨平台编排、低代码工作流和硬件互操作。([Nature][10])

它们主要回答：

> 实验能否在不同设备上被组织和运行？

科学编译器回答的是：

> 这套实验是否足以区分目标假设？
> 运行结果是否足以构造某一等级的科学主张？

两者不是同一层。

| 现有编排器  | 科学编译器         |
| ------ | ------------- |
| 编排动作   | 编译科学语义        |
| 验证命令合法 | 验证结论合法        |
| 输出数据   | 输出证据对象        |
| 关注执行成功 | 关注识别充分性       |
| 支持重放实验 | 支持重放从数据到主张的推理 |

---

## 9. 最值得形成的理论成果

### A. 声明健全性

若编译器输出：

[
\texttt{Claim<C4>}
]

则该对象必然满足所有C4证据谓词。

### B. 相对完备性

若在给定实验语法中存在能区分竞争模型的实验集合，编译器能够找到它，或给出有理论界限的近似结果。

### C. 最小性

证明所生成的判别实验集合在成本上最优或近似最优。

### D. 反例引导修复

实验产生反例后，不是让LLM“重新解释”，而是：

[
\text{模型检查失败}
\rightarrow
\text{生成反例}
\rightarrow
\text{修复模型或缩小适用域}
\rightarrow
\text{重新编译}
]

### E. 跨实验室证明可移植性

另一实验室接收的不是论文中的文字SOP，而是：

* 可执行协议；
* 质量门；
* 分析代码；
* 竞争模型；
* 主张构造规则；
* 原始证据哈希。

# 三个方向之间的关系

| 根问题      | 新的核心对象           | 主要学科           |
| -------- | ---------------- | -------------- |
| 看不全时怎样学习 | 信念状态、可观测性和不可辨识证书 | 数学、物理、控制       |
| 怎样防止系统自证 | 证伪博弈、科学资本和序贯证据   | 博弈论、统计、Agent   |
| 怎样防止结论越级 | 科学IR、类型系统和证明对象   | 计算机、形式化方法、实验设计 |

它们分别改变了自驱动科学的三个基本单位：

1. **方案一改变优化单位：从材料性能变为可知性；**
2. **方案二改变协作单位：从Agent共识变为激励相容的证伪竞争；**
3. **方案三改变输出单位：从自然语言报告变为证明携带的科学主张。**

---

# 哪一个最有原创价值

## 第一优先：可知性驱动的隐状态科学控制

这是最接近数学、物理和实验科学共同基础问题的方向。

它回答：

> 在只有代理观测、真实状态不可见的情况下，自主发现的理论边界在哪里？

它最有可能形成一个跨材料、化学、生物实验室都适用的新范式：

> **Observability-Limited Autonomous Science**

---

## 第二优先：对抗式可证伪科学市场

这是最可能改变科学Agent研究范式的方向。

它把当前的：

> 多Agent讨论得出答案

改成：

> 多Agent在真实实验和严格激励规则下竞争，只有能承受低成本合法证伪的主张才获得科学资本。

核心不是Agent数量，而是机制设计。

---

## 第三优先：证明携带的科学编译器

这是最有可能形成长期技术壁垒和行业标准的方向。

它建立：

* 科学假设语言；
* 实验判别编译；
* 结论类型系统；
* 机器可验证证据包。

最终不是只服务质子导体，而是给自主实验室建立一种新的“科学计算机体系结构”。

---

# 最凝练的研究主张

你们可以把整个项目的创新压缩成一句话：

> **我们不让自主实验系统直接追逐材料性能，而是让它首先判断什么能够被当前实验看见，通过对抗证伪决定什么值得相信，并要求每个科学结论携带一份机器可验证的证据证明。**

这三个方向中的任何一个做深，都比“LLM + BO发现了某个高性能材料”更具基础创新性；三者结合，则构成一套真正面向受限真实实验的**科学认知操作系统**。
