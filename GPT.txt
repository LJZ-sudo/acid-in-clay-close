# 二、这个项目目前真正成立的创新是什么

## 1. “复现地板—可辨识性天花板”框架是成立的

这是目前最强的概念贡献。

传统自主实验室经常把：

[
\text{算法找到的差异}
]

直接解释为：

[
\text{科学上有意义的改善}
]

你们引入复现地板以后，实际上规定了：

[
|\Delta f|<\delta_{\mathrm{repro}}
\quad\Rightarrow\quad
\text{不允许声称发现了有效差异}
]

再引入可辨识性天花板：

[
D!\left(p(Y|H_i),p(Y|H_j)\right)<\delta_{\mathrm{id}}
\quad\Rightarrow\quad
\text{不允许在 }H_i,H_j\text{ 中选边}
]

这形成了一个很好的科学结论区间：

[
\boxed{
\text{只有高于复现地板、低于证据天花板允许范围的主张，才可发布}
}
]

这个思想明显比“提高自主度”本身更有价值。现有SDL评价通常强调自主度、吞吐量、成本、精度、优化表现、任务复杂度、适应性与感知能力；你们增加了**科学主张能否超过真实测量分辨能力**这一层。([Nature][1])

但目前这个框架还是**经验型框架**，不是完整数学理论，后面会详细说明。

## 2. 真实系统对“确定性与LLM”的拆分是合理的

附件如实说明：

* Stage0测量分析、Stage1优化器、记忆、终止和安全是确定性的；
* LLM主要用于Stage1 Step5策略修正和Stage3上游假设、文献、描述符工作；
* S09候选和S10排序默认冻结为确定性实现；
* S14主张审计也是确定性的。 

这个架构比“什么都交给Agent”更可靠：

[
\text{LLM负责提出和解释}
]

[
\text{数值服务负责计算}
]

[
\text{规则系统负责权限和放行}
]

这与当前AI科学家安全研究强调的“人类监管—Agent约束—环境反馈”三层治理方向是一致的。([Nature][2])

## 3. 主张阶梯和前瞻冻结具有实际价值

C0–C5、EIS-only封顶C4、绝对化措辞拦截、冻结配方、SHA256链和`replay ≠ real`，都是扎实的科研工程。

更重要的是，附件没有把确定性候选排序冒充成LLM独立发现，而是把主张降低为：

> LLM从广义文献池中选择和重组，预测被冻结，再由真实EIS验证。

这大幅减少了最容易被审稿人攻击的“AI washing”。

# 三、与之前三个原创方向相比，当前完成到了哪里

## 原创点一：可知性驱动的隐状态双控

### 当前已经有的

* 多模型竞争；
* 经验可辨识性分析；
* 复现地板；
* 模型不能区分时限制主张；
* 一定程度的批次和质量分层；
* 负结果不进入性能结论。

### 当前缺少的

还没有真正实现：

[
b_t(z,\theta,H)
===============

p(z_t,\theta,H\mid D_t)
]

也就是没有一个明确维护以下潜态的信念状态：

* 样品含水或调理状态；
* 接触状态；
* 热历史状态；
* 仪器状态；
* 不可逆变化状态；
* 模型类别；
* 参数后验；
* 模型偏差。

现在的“可辨识性天花板”主要来自：

[
\Delta R^2\approx0.006
]

这只能支持：

> 在当前数据窗口和当前三个模型下，拟合优度非常接近。

它还不能严格支持：

> 当前EIS实验能力原则上无法区分这些机制。

两者差别很大。

可能存在三种解释：

1. 机制在当前实验动作集合下确实观测等价；
2. 数据点过少、温区过窄；
3. 所选模型和评分指标缺少判别力。

因此目前应该称：

> **经验模型不可区分性证据**

而不是严格的：

> **可辨识性天花板证明**

### 实现度评价

[
\boxed{\text{约35%}}
]

理论方向正确，但尚未形成：

* 状态空间模型；
* 在线后验；
* 观测性矩阵；
* 主动测量动作选择；
* 不可辨识证书；
* 为打破等价类而选择下一实验的双控策略。

## 原创点三：证明携带的科学编译器

### 当前已经有的

这是三个创新中实现度最高的：

* C0–C5主张阶梯；
* EIS-only硬封顶；
* 绝对化措辞正则；
* 前瞻冻结；
* 数据、建议和决策SHA链；
* 上游输入hash；
* 报告在主张审计后生成；
* `HOLD`偏置；
* 只读与可写服务分离；
* 非法写入和覆盖检查。

### 当前缺少的

目前更像：

> **审计式治理管线**

还不是严格的：

> **证明携带科学编译器**

主要缺少：

```text
RawSpectrum
ValidSpectrum
ReplicatedEvidence
ModelDiscriminationEvidence
Claim<C4>
```

这类真正的证据类型系统。

现在C级别主要依据claim类型映射：

```text
closed_loop_source_system -> C1
retrospective_validation  -> C2
llm_transfer_candidate    -> C2
prospective_validation    -> C3
mechanism_discovery       -> C4
```

风险是：**对象叫什么名字**和**它是否真的满足该等级证据条件**仍可能混在一起。

建议把：

```text
mechanism_discovery
```

改名为：

```text
mechanism_consistency
```

或者：

```text
mechanism_compatibility_claim
```

因为当前代码明确不允许真正的机制发现或因果确认。

另外，正则护栏能拦截“证明”“唯一说明”等词，但不能完全拦截语义过度声称。例如：

> “这些结果强烈揭示了界面质子跃迁的主导作用。”

它可能不命中禁词，但仍然可能越级。

LLM自身无外部反馈时的自我修正并不可靠，有时甚至会恶化表现，因此你们使用确定性外部验证器的方向是对的；下一步应从关键词拦截升级为证据谓词和语义蕴含验证。([OpenReview][3])

### 实现度评价

[
\boxed{\text{约50–60%}}
]

# 四、当前最需要警惕的测量与统计问题

## 1. KK只是警告，不是硬门

架构显示：

* 250 kΩ量程触顶和低频反向异常会一票否决；
* KK不通过只设置`kk_warning`，不会立即熔断。

如果`objective_valid`没有在后续另行排除KK失败数据，那么可能出现：

[
\text{KK可疑谱}
\rightarrow
R_b
\rightarrow
\sigma
\rightarrow
\text{BO数据库}
]

这会直接污染复现地板和闭环优化。

建议至少做三组结果：

| 分析     | 数据范围         |
| ------ | ------------ |
| 主分析    | 严格KK通过       |
| 敏感性分析  | KK warning保留 |
| 最坏情形分析 | 删除全部边缘谱      |

如果关键转变只在“warning可进入”的设定下存在，P1风险会很高。

## 2. Rb提取方法随温区切换，可能制造假转变

当前Rb提取依次使用：

* 深冷平台法；
* 过零法；
* 寻谷法；
* 等效电路兜底。

这个工程设计本身可以理解，但会引入一个危险混杂：

[
T
\rightarrow
\text{Rb提取方法}
\rightarrow
R_b
]

也就是说，在某个温度附近发生的方法切换，可能被解释成材料行为的分段。

必须补做：

1. 对所有温度统一使用每一种可行方法；
2. 给出四种方法下的 (T_{\text{break}}) 分布；
3. 在统计模型中加入`rb_method`；
4. 检查转变温度是否与方法切换温度重合；
5. 用人工合成谱注入已知Rb，测试方法路由是否产生假拐点。

## 3. 单调性过滤和相变发现存在潜在循环

架构说明，进入Arrhenius分析前会使用Rb单调性过滤，剔除“反常跳点”。

但项目的核心现象正是低温传输行为发生变化。

所以必须证明：

> 被过滤掉的不是你真正希望发现的非单调行为。

需要同时报告：

* 未过滤原始序列；
* 过滤后序列；
* 鲁棒回归但不删除点；
* 重尾误差模型；
* 含离群混合模型；
* 不同过滤阈值下的转变稳定性。

否则审稿人可能认为：

> 算法先删除不符合预期的点，再在剩余数据中找到稳定分段。

## 4. AICc权重等于1不等于物理唯一

AICc 3段模型权重达到1，只能说明：

> 在当前候选模型集合、误差假设和评分定义下，3段描述模型占优。

它不意味着：

* 真实物理过程有三种机制；
* 每个分段对应一种独立传导通道；
* 变点是唯一的；
* 结构发生了相变。

AutoEIS也明确将其输出描述为“statistically plausible equivalent circuit models”，而不是已确定的真实机制。([NIST][4])

建议把：

```text
phase transition
```

在论文主体中尽量改成：

```text
transport-regime transition
```

或者：

```text
conductivity-regime breakpoint
```

除非有更直接的相态证据。

## 5. 不同月份厚度协议需要作为层级变量

LRS 4月厚度约0.02 cm，6月标准化约0.07 cm。虽然电导率公式对厚度进行了归一化，但接触、膜均匀性、温度梯度和几何误差不一定线性消除。

建议模型至少包含：

[
y_{ijk}
=======

\mu
+\alpha_{\mathrm{month}}
+\beta_{\mathrm{thickness\ protocol}}
+u_{\mathrm{batch}}
+v_{\mathrm{sample}}
+\epsilon
]

否则“跨月份复现”既可能是优势，也可能是未建模的协议差异。

# 五、校准结果有价值，但目前不能说系统“判断更准确了”

你们的结果是：

* ECE显著降低；
* reliability项显著改善；
* resolution几乎不变。

这说明校准器完成的主要是：

[
\text{压低过度自信}
]

而不是：

[
\text{提高对正确与错误案例的区分}
]

这是一个很有意义的结果，但表述应严格限定为：

> **治理校准提高了概率陈述的可信度和拒答合理性。**

不要写成：

> **治理提高了发现准确率。**

另外，留一数据集评估中的独立单元数似乎仍然很少。建议给ECE、Brier和Murphy分解做：

* bootstrap区间；
* leave-one-material-family-out；
* leave-one-protocol-era-out；
* 温区外测试；
* 置信度—覆盖率曲线；
* 选择性风险曲线。

# 六、线B是目前最大的实证风险，但不是唯一风险

## G1确实必须完成

当前线B：

* 10个trial；
* 每个配方不同；
* 无同配方重复；
* 使用LRS复现地板代理凹凸棒土地板。

所以：

[
|\Delta f|<\delta_{\mathrm{LRS}}
]

不能严格推出：

[
|\Delta f|<\delta_{\mathrm{attapulgite}}
]

G1的三个重复非常必要。

## 但“唯一硬门槛是G1”过于乐观

我认为至少还有三个必须完成的分析门槛：

### G2：Stage0阈值与方法敏感性

包括：

* 250 kΩ门槛；
* 低频反向次数；
* KK门槛；
* Rb方法切换；
* 单调性过滤；
* AICc改善阈值；
* 分段候选范围。

附件同时指出`threshold_sweep`和`ablation`接口仍是placeholder stub。

如果手稿要强调代码治理，这两个最关键的阈值审计却是存根，会非常显眼。

### G3：BO优势必须区分“回放”与“真实前瞻”

“BO 4.1 vs random 5.5”如果主要来自replay或一个固定历史轨迹，最多支持：

> 在该历史数据和回放规则下，BO模拟找到较优点的平均步数较少。

它不能独立支持：

> 真实闭环中BO显著优于随机。

当前只有10个点和2轮前瞻，附件也明确不声称收敛。

### G4：LLM安全修正需要强基线

LLM把MOBO的R从约0.0285拉回0.28，能说明LLM应用了某种领域/安全先验。

但必须与以下基线比较：

1. 硬安全盒投影；
2. 最近安全点投影；
3. 约束GP；
4. 可行性分类器；
5. 风险惩罚采集函数；
6. 专家规则系统。

否则审稿人会说：

> 这不是LLM科学推理，只是把边界点拉回了人工认为安全的区域。

# 七、Agent部分最需要降温的地方

## 1. 当前系统是“混合治理系统”，不是完全自主科学家

由于：

* S09候选默认硬编码；
* S10排序默认确定性；
* S14主张审计确定性；
* v2科学声明恒HOLD；
* CHI自动化恒关；

最准确的定位是：

> **LLM辅助、确定性治理、真实湿实验闭环的混合自主系统。**

不是：

> **端到端自主发现智能体。**

这并不是缺点。事实上，当前ADePT框架也把自主性拆分为适应与学习、灵巧度、感知和任务复杂度，而不是一个“全自主/非自主”的二元标签。([Nature][1])

## 2. 只保存prompt哈希，不保存prompt内容，不足以复现

哈希能证明：

> 某段文本没有被更改。

但不能让第三方知道：

> 那段文本是什么。

再考虑：

* OpenRouter远程调用；
* 模型版本可能变化；
* 模型服务端非完全确定；
* 即使temperature为0，也不等于长期可复算；

因此当前是：

[
\text{可验证完整性}
]

但不是：

[
\text{可重复生成}
]

至少应保存：

* 完整system prompt和user prompt；
* 脱敏版本；
* 原始返回；
* 提供商请求ID；
* 模型精确标识；
* 所有采样参数；
* 工具输出；
* 时间戳；
* 失败与重试记录。

## 3. 词面护栏不是语义证据验证器

11条绝对化措辞正则是一道有用的最低防线，但它容易出现：

* 同义改写绕过；
* 合法语句误杀；
* 结论未用禁词但仍越级；
* 引文存在但不支持具体主张。

已有研究区分了“有引用”和“来源真的支持主张”，并专门构建系统评估来源相关性与支持性。([Nature][5])

下一步应检查：

[
\text{Evidence}
\models
\text{Claim}
]

而不只是：

[
\text{Claim中是否出现禁词}
]

# 八、工程架构上的强项和隐患

## 强项

* 坏数据在real模式下拒绝入库；
* 历史数据库去重和原子写入；
* suggestion、result、trace三件套哈希；
* S8不混入凹凸棒土训练；
* 报告生成位于主张审计之后；
* 只读API和可写API分离；
* v2工具不能写主线；
* 人工签名由工具验证但不自动生成。

这些做法非常好，尤其适合方法学论文。

## 隐患

### 1. Stage0产物存在两个入口

`stage0_result_bundle.json`不是由主离线入口直接生成，而由独立的`run_closure_offline.py`后处理生成。

这可能造成：

* 主流程成功但bundle未更新；
* bundle使用不同版本；
* 分析输入与原始manifest不同步。

建议把bundle生成纳入唯一事务：

```text
run_id
  ├── raw
  ├── QC
  ├── analysis
  ├── bundle
  └── provenance
```

任一步失败，整个Run保持未封存状态。

### 2. v2恒HOLD证明了安全偏置，却没有证明判定能力

`v2_claims_status="HOLD"`和`enables_chi_automation=False`恒定，说明它不会越权。

但它没有展示：

> 在什么充分条件下系统能从HOLD转到允许发布。

因此当前v2更像：

> 安全脚手架和完整性审计器。

还不是：

> 可自主判定主张是否充分的证明系统。

# 九、当前论文故事最容易散掉的地方

目前至少有四条故事：

1. 生物聚合物–黏土的亚零度传输转变；
2. 复现地板和校准；
3. MOBO+LLM闭环；
4. EIS-only的可辨识性天花板。

如果平铺呈现，审稿人可能认为是四个不够深的结果拼在一起。

建议唯一主线是：

# **Evidence-limited autonomous science**

逻辑顺序：

[
\text{测量重复性}
\Rightarrow
\text{定义复现地板}
]

[
\text{模型竞争}
\Rightarrow
\text{定义经验可辨识性上限}
]

[
\text{闭环决策}
\Rightarrow
\text{候选差异是否超过地板}
]

[
\text{校准与主张治理}
\Rightarrow
\text{结论是否保持在地板和天花板之间}
]

这样：

* P1是案例；
* P2是数学/统计核心；
* P3是系统验证；
* 不可辨识性是边界证明。

而不是把“亚零度转变”和“AI Agent平台”并列为两个中心。

# 最终评价

## 这项工作目前“好”在哪里

它最难得的是：

> **没有把系统能运行，偷换成系统发现了真理。**

真实数据、真实闭环、负结果、代理地板、不可辨识、冻结逻辑、存根、确定性候选和LLM有限作用都被公开标注。这种诚信设计本身就比大量只展示成功案例的Agent实验更可信。

## 它目前“不够好”在哪里

它仍主要靠：

* 经验阈值；
* 硬编码规则；
* 词面护栏；
* 回放对照；
* 小样本校准；
* 一个代理复现地板；
* 经验模型拟合接近；

来实现我们之前提出的三个底层创新。

所以当前最准确的定位是：

> **你们已经建成了“科学认知操作系统”的审计、治理和真实实验底座，但可知性双控、对抗证伪市场和证明携带编译器仍主要处于原型或脚手架阶段。**

我不同意附件中“唯一硬门槛只有G1”的判断。**G1是唯一必须新增的湿实验门槛，但不是唯一的方法学门槛。** 至少Stage0敏感性、强基线、prompt可复现性和经验不可辨识性措辞，也需要在投稿前解决。

完成这些补强后，这项工作真正有机会成立的核心贡献不是：

> LLM发现了某种材料。

而是：

> **在只有单一传输观测、实验昂贵且模型不可唯一识别的现实条件下，一个自主实验系统如何定量知道何时可以声称、何时必须拒绝、以及一个算法建议是否超出了实验自身的复现能力。**
