## 📊 CSV 文件说明

### breakpoints_data.csv
每个变化点一行，包含：

| 列名 | 说明 |
|------|------|
| `material` | 材料类型（S8 或 S60） |

## 🔬 物理意义

### 变化点的含义
Arrhenius 图中的变化点（breakpoint）表示：
- **传导机制转变**：不同温区采用不同的质子传导机制
- **活化能变化**：Ea 从一个值跃迁到另一个值
- **结构相变**：可能伴随水分状态变化或晶体结构调整

### 215 K 附近的聚集
- **29 个变化点**集中在 205-225 K 区域
- **可能原因**：
  1. 结构水冻结温度（~-60°C）
  2. 从 Grotthuss 机制转向 Vehicle 机制
  3. 粘土层间水的相变温度
- **共性特征**：S8 和 S60 均显示此聚集，说明是材料共性

### 高温区变化点（270-275 K）
- **13 个变化点**集中在高温区
- **可能原因**：
  1. 高温结构弛豫
  2. 游离水蒸发影响
  3. 质子传导从受限到相对自由

## 🔧 Origin 重绘指南

如需在 Origin 中重新绘制：

### 1. 导入数据
```
File → Import → Single ASCII
选择: breakpoints_data.csv
```

### 2. 创建直方图
```
Plot → Statistics → Histogram
X: temperature_K
Group by: material
Bins: 180-280 K, Bin Width = 5 K
```

### 3. 设置颜色
```
S8: RGB(233, 30, 99)  粉红色
S60: RGB(33, 150, 243) 蓝色
Transparency: 30%
```

### 4. 添加高亮区域
```
Plot → Add Line → Vertical Span
X1 = 205, X2 = 225
Color: Orange, Alpha = 15%
```

### 5. 添加标注
```
Insert → Text
位置1 (左上): "Total: 128 breakpoints\nS8: 82, S60: 46"
位置2 (215 K 上方): "29 breakpoints\n(205-225 K)"
```
