【Origin 快速绘图步骤】
───────────────────────────────────────────────────────────────

1. 导入数据
   File → Import → Single ASCII
   - 选择 CSV 文件
   - Header Lines: 1
   - 只导入前 36 行（数据部分）

2. 设置列属性
   - Column A (1000_T_K_inv): X 轴
   - Column E (log10_sigma_mS_cm): Y 轴

3. 绘制散点图
   选中 A 列和 E 列 → Plot → Symbol → Scatter
   - 点大小: 6-8 pt
   - 颜色: 深灰色 (RGB: 44,62,80)

4. 添加拟合线（手动）
   对于每段，新建两列 X_fit, Y_fit：
   
   【Segment 1】
   X 范围: 3.333 – 4.087
   Y = ((-4.699 + 6.9078) / 2.3026) - (0.0725 / 0.1984) * X
   颜色: 粉红 (#E91E63)
   
   【Segment 2】
   X 范围: 4.134 – 4.523
   Y = ((17.325 + 6.9078) / 2.3026) - (0.5428 / 0.1984) * X
   颜色: 绿色 (#4CAF50)
   
   【Segment 3】
   X 范围: 4.725 – 5.413
   Y = ((49.957 + 6.9078) / 2.3026) - (1.1328 / 0.1984) * X
   颜色: 橙色 (#FF9800)

5. 设置坐标轴
   下横轴: 1000/T (K⁻¹), 范围 3.0-5.5, 刻度 0.5
   上横轴: T (°C), 用公式 T=1000/X-273.15 转换标签
   纵轴: log σ (mS·cm⁻¹)

6. 添加边界虚线
   Plot → Add Line → Vertical
   X = 4.134 和 4.725
   虚线，灰色，1 pt

7. 添加标注
   - Ea 值：在每段中间标注 "Ea = 0.07 eV" 等
   - R² 值：在左下角图例中
     "Segment 1 R²=0.528"
     "Segment 2 R²=0.998"
     "Segment 3 R²=0.987"

【常见问题】
───────────────────────────────────────────────────────────────

Q: 为什么用 log₁₀ 而不是 ln？
A: 常用对数数值更直观，两者只差常数 2.303

Q: Origin 中如何快速计算 Y 值？
A: Set Column Values: log(Col(sigma_S_cm) * 1000)

Q: 拟合线公式中的 6.9078 和 2.3026 是什么？
A: 6.9078 = ln(1000), 2.3026 = ln(10)
   用于从 ln(σ) 转换到 log₁₀(σ/mS·cm⁻¹)

Q: 0.1984 是什么？
A: kB × 1000 × ln(10) = 8.617333e-5 × 1000 × 2.3026 ≈ 0.1984
   简化计算斜率 B = -Ea / 0.1984
