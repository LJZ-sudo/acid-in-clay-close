### 4. 单位换算

```
原始电导率: σ = 0.001871 S/cm
           ↓ ×1000
转换单位:   σ = 1.871 mS/cm
           ↓ log₁₀
Y 轴值:     log₁₀(1.871) = 0.272
```

### 5. Origin 绘图步骤概要

1. **导入数据**: Import ASCII，只导入前 36 行
2. **设置列**: A 列(1000_T_K_inv)为 X，E 列(log10_sigma_mS_cm)为 Y
3. **绘制散点**: Plot → Scatter，深灰色点
4. **添加拟合线**: 使用第 2 部分的 Ea 和 ln_sigma0 参数
5. **双横轴**: 上横轴显示 T(°C) = 1000/X - 273.15
6. **边界虚线**: X = 4.134 和 4.725 画灰色虚线
7. **标注**: 
   - Ea 在每段中间
   - R² 在左下角图例

## 🔬 拟合公式说明

### Arrhenius 方程
```
ln(σ) = ln(σ₀) - Ea / (kB × T)
```

其中：
- σ: 电导率 (S/cm)
- Ea: 活化能 (eV)
- kB: 玻尔兹曼常数 = 8.617333×10⁻⁵ eV/K
- T: 温度 (K)

### 转换为图中坐标
```
Y = A + B × X

其中:
  X = 1000/T (K⁻¹)
  Y = log₁₀(σ / mS·cm⁻¹)
  B = -Ea / 0.1984  （斜率）
  A = [ln(σ₀) + ln(1000)] / ln(10)  （截距）
```

### Origin 拟合线计算公式

对于每段 i：
```
Y_fit = (ln_sigma0 + 6.9078) / 2.3026 - (Ea / 0.1984) × X
```

其中：
- 6.9078 = ln(1000)
- 2.3026 = ln(10)
- 0.1984 = kB × 1000 × ln(10)

**实例**（Segment 2）：
```
Ea = 0.5428 eV
ln_sigma0 = 17.325
X 范围: 4.134 – 4.523

Y_fit = (17.325 + 6.9078) / 2.3026 - (0.5428 / 0.1984) × X
     = 10.534 - 2.735 × X
```

## 💡 常见问题

**Q: 为什么不直接用 Python/Matplotlib 生成的图？**  
A: Origin 提供更精细的样式控制，便于根据期刊审稿意见快速调整。

**Q: 可以用 Excel 绘图吗？**  
A: 不推荐。Excel 无法精确控制双横轴对齐和科学标注样式。

**Q: Segment 1 的低 R² 是否需要在图中说明？**  
A: 建议在图注（caption）或正文中简要说明高温段的非线性特征。

**Q: 如何验证我的拟合线是否正确？**  
A: 检查拟合线的斜率 B = -Ea/0.1984 是否与 CSV 中的 Ea 一致。
