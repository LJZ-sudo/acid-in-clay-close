## 2. E1 设计(测线 B 直接地板;回溯式,不需新 R/N)

**主测(必做)——复现 campaign 最优**
- 配方:**R = 0.186, N = 1.029**(trial 1 同配方)。
- 独立片数:**新增 3 片**独立压片(与已存 trial 1 合计 4 次独立重复 → 可给出 σ 散布的 std 与 p90)。
- 工艺标准化:压片厚度统一到 **~0.07 cm**(与线 A 6 月标准化批、复现地板口径一致),逐片记录真实厚度。
- 测量:同一宽温 EIS 协议(室温 → 约 −90 °C),每点充分热平衡,两电极构型与既往一致。

**副测(可选,验证地板是否随位置变化)——复现一个高 σ 点**
- 配方:**R = 0.50, N = 1.20**(trial 5,σ 最高),**新增 2 片**。
- 作用:检验复现地板在体系内是否均匀(最优点 vs 高 σ 点),增强"地板"普适性论证。

**总工作量**:必做 3 片(+可选 2 片)= **3–5 次 EIS 宽温扫**,无任何结构表征、无新仪器。

## 3. E1 分析与验收(直接替换代理地板)
- 对同配方重复,在匹配温度算 **|Δlog₁₀σ|**,分 warm(≥ −20 °C)/ cold(< −20 °C)给中位与 p90。
- 传播到 **combined_score 地板**(同 §11.3 方法),得到**线 B 体系自身**的地板带。
- 用线 B 直接地板重做 §11.3 的"候选差 vs 地板"对照图 → **去掉"代理"caveat**;无论地板比代理更紧或更松都如实报告。
- 验收门:≥3 次独立重复即可给出可用的 std;若副测做了,额外报告地板均匀性。**结论随数据走,不预设方向。**

## 4. 下一个实验的 R/N(若继续优化;须先冻结再测)

> ⚠️ 优先级:**E1(测地板)应先于新探索点**——因为 §11.3/③ 已表明最优附近候选差 < 地板,在没测准地板前继续微调顶端=继续"优化噪声"。下面 R/N 仅作**冻结前的数据依据建议**,实际值须经官方 MOBO+LLM 管线产出并 git 盖时间戳。

**建议(二选一,按目的)**:

| 选项 | R | N | 目的 / 依据 | 风险 |
|---|---|---|---|---|
| **A 低 R 边缘试探(推荐)** | **≈0.15** | **≈1.03** | 真实趋势=R 越低越好,且 trial 1(R0.186)已证可行;R0.15 测"低 R 改善是否延续 or 饱和",是当前**信息量最大**的探索 | 接近酸量安全下限 → 必过 LLM 护栏复核 |
