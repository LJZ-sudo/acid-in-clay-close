# 集成版温控CHI测量系统使用说明

## 系统概述

本系统将温度控制和CHI电化学测量功能完全集成，实现了自动化的变温EIS测量流程。

## 主要功能

1. **自动降温控制**：按设定步长自动降温
2. **自动CHI测量**：在每个目标温度点自动执行EIS测量
3. **数据自动保存**：测量数据自动保存到指定位置
4. **相变点检测**：自动检测相变并执行精细测量
5. **实时监控**：实时显示温度变化和测量状态

## 使用步骤

### 1. 准备工作

- 确保CHI电化学工作站软件已打开
- 确保温控设备连接到正确的串口（默认COM3）
- 确保模板文件在 `auto_control` 目录下

### 2. 运行程序

#### 方法一：使用启动脚本
```bash
python start_integrated_control.py
```

#### 方法二：通过前端界面
- 在网页界面中启动温度控制
- 系统会自动使用集成版控制器

### 3. 参数配置

在 `start_integrated_control.py` 中可以修改以下参数：

```python
# 温度参数
T_START = 10        # 起始温度(°C)
T_END = -30         # 目标温度(°C)
COARSE_STEP = 10    # 粗测步长(°C)
FINE_STEP = 3       # 精细步长(°C)

# CHI测量参数
CHI_PARAMS = {
    "material": "Cu",               # 材料名称
    "highf": "10000",              # 高频(Hz)
    "lowf": "1",                   # 低频(Hz)
    "initV": "0",                  # 初始电位(V)
    "your_position": r"C:\Users\HP\Desktop\chi_data",  # 保存路径
}
```

## 工作流程

1. **降温阶段**
   - 设置目标温度
   - 等待温度稳定
   - 周期性读取温度（每2秒）

2. **测量阶段**
   - 到达目标温度后暂停降温
   - 自动控制CHI软件执行EIS测量
   - 等待测量完成
   - 自动保存数据

3. **数据处理**
   - 读取CHI保存的数据文件
   - 计算Rb值和电导率
   - 检测相变点
   - 保存处理结果

4. **循环控制**
   - 恢复降温
   - 继续到下一个目标温度
   - 重复测量过程

## 数据输出

### 1. 实时数据
- 温度历史：`experiment_data/temperature_history.json`
- 测量记录：`experiment_data/measurement_history.json`
- 相变点：`experiment_data/phase_transitions.json`

### 2. CHI原始数据
- 保存位置：`C:\Users\HP\Desktop\chi_data\`
- 文件格式：`材料_T温度C_highf频率_lowf频率_initV电位.txt`

### 3. 处理后数据
- EIS数据：`experiment_data/eis_data/eis_温度C_时间戳.txt`
- 实验报告：`experiment_data/experiment_report.json`

### 4. 图表
- 温度曲线：`experiment_data/temperature_profile.png`
- 电导率曲线：`experiment_data/conductivity_profile.png`

## 注意事项

1. **CHI软件设置**
   - 确保CHI软件处于就绪状态
   - 确保测量参数已正确设置
   - 确保保存路径有写入权限

2. **温度控制**
   - 严格降温模式用于大幅降温（≥10°C）
   - 精细测量模式用于相变点附近
   - 每个测量点保持3分钟

3. **错误处理**
   - 如果CHI测量失败，会使用模拟数据
   - 如果温度读取失败，会重试5次
   - 所有错误都会记录在日志中

## 故障排除

### 问题：CHI测量无法启动
- 检查CHI软件是否打开
- 检查模板文件是否存在
- 降低模板匹配置信度

### 问题：温度读取超时
- 检查串口连接
- 检查温控设备电源
- 重启程序

### 问题：数据保存失败
- 检查保存路径权限
- 确保磁盘空间充足
- 检查文件名是否合法

## 技术支持

如遇到问题，请检查：
1. 控制台输出的错误信息
2. `experiment_data` 目录下的日志文件
3. CHI软件的状态和设置
