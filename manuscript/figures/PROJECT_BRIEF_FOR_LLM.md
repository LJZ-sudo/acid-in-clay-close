## 0. 一句话定位

这不是一篇普通材料论文，也不是一个普通的 AI agent 演示，而是一个
**「受物理与质量控制约束、且对外主张受审计」的智能体材料发现项目**
（physics/QC/claim-governed agentic materials discovery）：
用一个智能体在**「数字世界 ↔ 物理世界」**之间，对质子导体（酸-黏土 / 凹凸棒土体系）做
**电化学阻抗谱（EIS）闭环发现**。它的灵魂是两条：**证据约束**（一切结论按证据强度分级）与
**不过度声称**（绝不把数学建议或回溯拟合说成「发现」「收敛」「普适最优」）。

## 1. 我们想做什么 / 目标 / 现在在做什么

- **想做什么**：把「酸-黏土」质子传导的成功原理（磷酸被约束在黏土高比表面域、靠 packed-acid +
  Grotthuss 机制快速传质并抑制酸流失），**迁移**到「生物聚合物–黏土膜」这一新材料家族，并找出
  **在低温/冷却过程中仍能维持质子通路连续性**的体系。
- **目标（投稿）**：发表到**方法/计算型子刊**（如 Digital Discovery；证据到位可上探材料类子刊）。
  贡献定位是**「受治理的智能体发现方法学」**，不是「发现了某种新材料」。
- **现在在做什么**：

## 3. 系统架构（**最重要** · 代码级事实）

整体是一条**单向、可审计的「发现 → 执行 → 审计」流水线**，分四个 Stage（0→1→2→3）。
顶部有一层**贯穿全程的智能体组件**；关键「写入」处有**门禁**；链路末端有**确定性主张审计**守门。

```
        ┌───────────── 智能体组件层（贯穿 Stage 1 / 3）─────────────┐
        │  记忆Memory(仅追加·可回放)  自省Critic(生成-自评-修订)        │
        │  心跳Heartbeat(状态遥测)    模型网关LLM-Gateway(确定性解码·JSON) │
        └──────────────────────────────────────────────────────────┘
                ▼（作用于）                         ▼（作用于）
  [Stage0 测量/QC] ──► [Stage1 闭环优化] ──► [Stage2 统计/种子] ──► [Stage3 机制/迁移/审计] ──► 〔主张审计门〕──► 对外主张
        ▲                    │                                                                         │
        └──── 人工批准·合成 ◄──┘（闭环回边）                                          〔门禁: 哈希绑定人工批准·仅追加·禁覆盖〕
```

### Stage 0 · 测量与质量控制（**物理世界**）
目录 `V1.0-qianduan-mainline/stage0_measurement/`。负责把真实样品变成可信数据。
- **采集**：宽温 EIS（CHI 电化学工作站 + 温控；`controllers/online_workflow.py`、`modules/automation/chi_executor.py`）。
- **解析**：DTA/CHI 文件解析（`modules/io_utils/dta_parser.py`、`chi_parser.py`）。
- **质量控制（QC）**：
  - Kramers–Kronig 校验 `algorithms/kk_validation.py`（因果/线性/稳态检验，lin-KK 残差）。
  - 体相电阻 Rb 抽取 `algorithms/rb_fitting.py`（含手动 vs 自动一致性）。
  - 数据质量评估 `data_quality.py`、相检测 `phase_detect.py`（用 LLM 辅助，模型 gpt-5.2）。
- **物性**：电导率 σ(T) → **分段 Arrhenius** `algorithms/arrhenius.py`（得 Eₐ、转变温度）；
  DRT 分析 `algorithms/drt_analysis.py`（仅探索用途）。
- **产物**：通过 QC 的 σ(T) 与描述符量。

### Stage 1 · 闭环优化执行（**数字↔物理 的桥**）
目录 `stage1_optimization/`。这是「数字世界提议 → 物理世界验证」的闭环。
- **优化器**：单目标贝叶斯优化（高斯过程 + 期望改进）；当前升级为**多目标贝叶斯优化 MOBO（ParEGO）**
  （`optimizers/mobo_optimizer.py`），目标为 室温电导↑ / 高温段 Eₐ↓ / 低温过量势垒↓。
- **设计变量**：R（酸/水摩尔比）与 N（液/黏土质量比）。
- **LLM 物理护栏**：`agents/llm_client.py`，确定性解码（temperature=0），对优化器的原始建议做安全/物理校正，
  并记录提供方、模型、提示哈希、用量作为溯源。
- **闭环主循环**：`run_optimization_loop.py`。流程：MOBO 提议 (R,N) → LLM 护栏校正 → **人工批准** →
  合成 → 回 Stage0 测 EIS → QC → 评分/Pareto 门 → **仅追加**写回历史 → 下一轮。
- **产物**：带内容哈希与时间戳的推荐配方 + 闭环轨迹（不可回溯篡改）。

### Stage 2 · 统计证据与种子
目录 `stage2_statistics/`。做证据清洗与聚合，导出供 Stage3 机制分析用的「种子」数据。

### Stage 3 · 机制推理 / 迁移 / 排序 / 验证 / 审计（**数字世界**）
目录 `stage3_mechanism/src/s8_stage3/`。这是迁移智能体的主战场，由 **14 个有序 agent（S01–S14）** 组成一条链：

| 代号 | agent（文件） | 职责 |
|---|---|---|
| S01 | `s01_data_auditor` | 数据审计 |
| S02 | `s02_segment_builder` | 分段（Arrhenius 分段） |
| S03 | `s03_evidence_builder` | 证据构建 |
| S04 | `s04_hypothesis_generator` | 机制假设生成 |
| S05 | `s05_literature_scout_mechanism` | 机制文献检索 |
| S06 | `s06_mechanism_arbiter` (+`s06b_design_principle_extractor`) | 机制仲裁 / 设计原理抽取 |
| S07 | `s07_descriptor_extractor` | **描述符抽取**（创新点 2 的核心） |
| S08 | `s08_literature_scout_materials` | 材料文献检索（OpenAlex） |
| S09 | `s09_candidate_family_generator` (+`s09b_top_list_to_campaign_seed`) | 候选家族生成 / 转 campaign 种子 |

- **末端 S14 主张审计**：独立于生成结论的 LLM，依结构化证据 + 预定义措辞规则给出**可回放裁决**。

### 智能体组件层（agent harness · 让它「算得上 agent」）
不是一次性提示，而是真正的智能体部件，贯穿 Stage 1/3：
- **记忆 Memory**：仅追加（append-only）、可确定性回放的实验与决策记录。
- **自省 Critic**：「生成–自评–修订」循环，内置**过度声称检测**。
- **心跳 Heartbeat**：运行状态遥测。
- **模型网关 LLM Gateway**：结构化输出、确定性解码、JSON schema 校验。

### 门禁与治理（**结构性的，不是事后声明**）
- 闭环写入历史前：**内容哈希绑定的人工批准**，批准前禁止写入。
- 自动阻抗采集：取得「宕机/空池对照」证据前**阻断**，只允许人工核验的测量。
- 所有写入**仅追加、禁覆盖**；门禁默认**保守暂停**偏置（存疑则挂起等人工）。
- **主张审计门**三出口：**通过**（可对外主张）/ **降级**（降到补充或探索级）/ **拒绝**（拦截「独立发现」「普适最优」等过度声称）。

### 前后端（驾驶舱）
- **后端** `backend_api/`：FastAPI（端口 8000），`routers/*` 提供只读看板 + 控制；
  `GET /api/provenance` 暴露 git 锚 + LLM + 线 B 官方 recipe。
- **前端** `frontend/`：React + Vite + Ant Design 驾驶舱（端口 5173）。
- **重要原则**：驾驶舱**只展示「测量 + 实证留痕」**；「允许/禁止声称」这类治理文字归论文与预注册层，**不放前端**。

## 4. 关键材料与结果（用于数据图）

- **三类体系**：LRS（莲藕淀粉，**正验证**）/ CHITO（壳聚糖，**边界验证**）/ 玉米淀粉（**广义对照**）。
- **核心现象**：233 K 时 LRS 电导比 CHITO 高约 60–100×；LRS 冷尾平滑延伸至 −81 °C，CHITO 约 233 K 骤降约两个数量级。
- **活化能对标**：LRS 高温段 Eₐ ≈ 0.037–0.042 eV，与已报道最低势垒的体系可比（POP-2020 0.039、MFM-300(Cr) 0.040），
  远低于酸-黏土母体系（≈0.12 eV）。CHITO 高温段无稳定 Arrhenius 区，Eₐ 不适用。
- **闭环**：单目标 8 试验演示净改进为 0（**诚实 null**）；多目标已冻结前瞻推荐（如 R=0.28/N=0.96），待合成验证。

## 5. 诚信护栏（项目灵魂 · 任何图/文都不得违反）

1. 闭环结果**无论收敛与否都如实报告**；未越阈值就写「执行成功但未实现 Pareto 扩展（诚实 null）」。
2. 迁移智能体的对外主张上限是**「选择/重组」**，**禁止**「独立发现」。
3. 前瞻性主张必须有**实验之前的 git 时间戳**（冻结 → 推送远端盖戳 → 才开始测量）。
4. 描述符是**唯象的操作型判据**；机制解读是**文献锚定的假说**，不主张直接结构/谱学证据。
